## HS-01. Re-proved

Statement: λ_j distinct non-zero, c_j positive integers, |Σ c_j λ_j^n| ≤ C·exp(o(n))·B^n for n ≥ 1; then |λ_j| ≤ B.

Proof. The series Σ_n (Σ_j c_j λ_j^n) z^n has radius of convergence at least 1/B, and near 0 it equals
Σ_j c_j λ_j z/(1 − λ_j z). That rational function has a simple pole with non-zero residue at each 1/λ_j, and the
poles are distinct, so none cancels. The series is holomorphic in |z| < 1/B and agrees with the rational function
there, so 1/|λ_j| ≥ 1/B. ∎ Only c_j ≠ 0 is used. Positivity is what guarantees c_j ≠ 0 after the eigenvalues of two
modules are merged, which is how SG-09 uses it. Frobenius is invertible on cohomology, so the eigenvalues are
non-zero.

## HS-03. Re-proved, in the form SG-09 uses

Let t_{i,h} be functions on A = E^d with |t_{i,h}| ≤ B′, for 1 ≤ i ≤ k and h in E, and
P(x) = Σ_{i<k} b_i(x_i, x_{i+1}) + c with b_i non-degenerate. For h ≠ 0 write the sum
S_h = Σ_x ∏ t_{i,h}(x_i)·ψ(hP(x)) as ψ(hc)·⟨v₁, K₁D₂K₂ ⋯ D_{k−1}K_{k−1} v_k⟩ with K_i(x, y) = ψ(h b_i(x, y)),
D_i the multiplication by t_{i,h}, and v₁, v_k the end weights. K_i K_i^* = Q^d because Σ_y ψ(h b_i(x − x′, y))
vanishes unless x = x′; so ‖K_i‖ = Q^{d/2}, ‖D_i‖ ≤ B′, ‖v‖₂ ≤ B′Q^{d/2}, and
|S_h| ≤ B′^k Q^{d(k+1)/2}. Nothing in this uses that the weights are the same for different h or i.
Summing over h, with Σ_h ψ(hP) = Q·1_{P=0}: the h = 0 term is ∏_i (Σ_x t_{i,0}(x)).

In SG-09, t_{i,h}(x) = Σ_{u in π^{-1}(x)} τ(u)·ψ(h g_i(u)) with τ the trace function. At h = 0 the phases are 1 and
Σ_x t_{i,0}(x) = Σ_{u in U(F_Q)} τ(u) = M for every i, so the zero mode is exactly M^k, and
Q·N − M^k = Σ_{h≠0} S_h has absolute value at most (Q − 1)·B′^k Q^{d(k+1)/2}, with B′ = B·C·Q^{w/2}. This is the
bound (parsevalbound) of the text. ✓.

## SG-08. Re-proved

Setting: X = U^k smooth affine of pure dimension D = kd, Y a smooth hypersurface in X, 𝓕_k lisse, and the
restriction H^a(X, 𝓕_k^∨) → H^a(Y, 𝓕_k^∨) an isomorphism for a < D − 1 and injective for a = D − 1.

1. Duality. H^a(X, 𝓕_k^∨) is dual to H_c^{2D−a}(X, 𝓕_k)(D), and H^a(Y, ·) to H_c^{2D−2−a}(Y, 𝓕_k)(D − 1). The
   transpose of restriction is therefore a Frobenius-equivariant map H_c^j(Y)(−1) → H_c^{j+2}(X), j = 2D − 2 − a:
   an isomorphism for j > D − 1, surjective for j = D − 1. ✓ (twist: (D − 1) − D = −1).
2. Vanishing. H_c^j(X) = 0 for j < D and H_c^j(Y) = 0 for j < D − 1 (Artin vanishing for the dual sheaf, then
   duality). ✓
3. Counting. With T_b = H_c^{D+b}(X), W_a = H_c^{D−1+a}(Y): M^k = Σ_b (−1)^{D+b} Tr(T_b) and
   q^n N = Σ_a (−1)^{D−1+a} Tr(W_a(−1)), because F acts by q on Q̄_ℓ(−1). Hence
   (−1)^{D−1}(q^n N − M^k) = Σ_a (−1)^a Tr(W_a(−1)) + Σ_b (−1)^b Tr(T_b). ✓
4. Cancellation. For a ≥ 1 the map of step 1 identifies W_a(−1) with T_{a+1}, which carries the opposite sign.
   What is left is Tr(W₀(−1)) − Tr(T₁) + Tr(T₀) = Tr(K_k) + Tr(T₀), K_k the kernel of the surjection W₀(−1) → T₁. ✓
5. Künneth. T₀ = H_c^D(U^k, 𝓕^{⊠k}) = H_c^d(U, 𝓕)^{⊗k}, because every factor vanishes below d. ✓

So (−1)^{D−1} R = Tr(F^n, H_c^d(U, 𝓕)^{⊗k}) + Tr(F^n, K_k), both with sign +. The sign of the text is right: the
bottom group of X enters −M^k with (−1)^{D+1} and the bottom group of Y enters q^nN with (−1)^{D−1}.

Example (mine). U = A¹, k = 2, Y: xy + ax + by + c = 0 with ab ≠ c, a smooth conic isomorphic to G_m. N = q − 1,
M = q, R = −q. T₀ = 0, T₁ = 0, K₂ = H_c¹(G_m)(−1) with trace q, and (−1)^{D−1}R = q. ✓ The cancelled pair is
H_c²(Y)(−1) = H_c⁴(A²).

If Y is empty the hypothesis forces H_c^j(X) = 0 for j > D and the identity reads (−1)^{D−1}(−M^k) = Tr(T₀). ✓

## SG-09. Confirmed, with a fix of the citation route

### What Katz's statements say, and that they apply (read at pp. 180–181)

- Theorem 3.4: k algebraically closed of characteristic p ≠ ℓ, V separated of finite type, f an arbitrary function
  on V, π : V → A^n quasi-finite, L perverse on V. Then there is a dense open set of affine maps (A, b) for which,
  with f_{A,b} = f + Aπ + b, H^a(V, j_!j^*L) = 0 for a < 0 and the restriction of H^a(V, L) to the hypersurface
  f_{A,b} = 0 is an isomorphism for a < −1 and injective for a = −1.
- Corollary 3.4.1: the same for V a local complete intersection of pure dimension d > 0 and a lisse sheaf 𝓕:
  isomorphism for a < d − 1, injective for a = d − 1.

SG-09 takes V = U^k over the algebraic closure (smooth, so a local complete intersection, of pure dimension
D = kd > 0), π the closed immersion by all the vertex coordinates into A^{sk} (quasi-finite), f the fixed path
form (an arbitrary function is allowed), the lisse sheaf 𝓕_k^∨, and the family f + Σ g_i + c: here A = Σ g_i is a
general linear form on A^{sk}, which is a sum of linear forms in the s coordinates of each vertex, and b = c.
**The hypotheses are met word for word, and conclusion (2) is exactly the hypothesis of SG-08.** ✓

### Whether the proofs use weights

- **Appendix A.3–A.5 (read, pp. 219–221).** On p. 152 Katz says that the Appendix gives a simpler, more direct
  proof of weak Lefschetz, explained to him by Deligne. A.3: for a separated morphism f : X → P of finite type to a
  projective space and a generic hyperplane H, the map β_!Rg_*α^*K → Rf_*α_!α^*K is an isomorphism; the proof is
  the Künneth formulas (SGA 4 XVII 5.4.3) with biduality (SGA 4½, Th. finitude 4.3) in the universal situation,
  generic base change (Th. finitude 1.9) over the space of hyperplanes, and proper base change. A.5: if f is
  quasi-finite and K perverse, then for generic H the groups H^i(X, α_!α^*K) vanish for i < 0, equivalently the
  restriction to f^{-1}H is an isomorphism for i < −1 and injective for i = −1; the proof is A.4, duality, the fact
  that a quasi-finite direct image with proper support keeps semiperversity, and the cohomological dimension of
  affine schemes. **No weight, purity (in the sense of weights) or Weil II enters.** The inputs are SGA 4
  (Artin's theorem, Künneth, base change), the finiteness theorems of SGA 4½, Verdier duality and the elementary
  part of BBD chapter 4. I re-derived the statement independently before opening the paper (next paragraph), and
  the two arguments agree.
- **The printed proof of Theorem 3.4 and Cor. 3.4.1** does not go through the Appendix. It goes through
  Corollary 3.0.2, that is the Main Theorem 1.5 (semiperversity of the transform), with Lemma 3.0.1
  (Euler–Poincaré formula) and duality (3.1–3.3). The proof of 1.5 (pp. 155–158, read) is by the Fourier transform:
  it uses that the Fourier transform is involutive (Brylinski 9.3) and keeps semiperversity because "forget
  supports" is an isomorphism (Katz–Laumon 2.4.1), the Künneth formula, the projection formula, and the vanishing
  of RΓ_c(A¹, 𝓛_ψ). None of these is a weight statement as cited, and from memory the two references rest on
  local acyclicity and formal properties, not on weights; but I did not open Brylinski or Katz–Laumon, so I do not
  certify that chain.

### The fix

Deduce the fixed-f statement from A.5, in the text, instead of citing Cor. 3.4.1 for it:

> Let Γ = (z, f) : U^k → A^{sk+1} ⊂ P^{sk+1}, a closed immersion into the affine space, hence quasi-finite. Apply
> A.5 to Γ and K = 𝓕_k^∨[D]. The good hyperplanes form a dense open subset of the dual projective space, so they
> meet the chart "coefficient of the last coordinate ≠ 0" in a dense open subset; after scaling that coefficient to
> 1, the hyperplane sections of the chart are exactly the hypersurfaces f + Σ g_i + c = 0.

This is the same chart argument the text already uses for smoothness, so both properties come from generic
hyperplanes for one immersion. Cor. 3.4.1 can stay as the statement in the literature. With this the only inputs of
the Lefschetz step are those listed under A.3–A.5.

### My own proof of the Lefschetz input (independent re-proof)

Let X ⊂ A^N be closed, X̄ its closure in P^N, k : X → X̄ (an affine open immersion), K perverse on X, H a
hyperplane, Y = X ∩ H, j : X − Y → X, j̄ : X̄ − H → X̄, k′ : X − Y → X̄ − H. (a) For generic H the base-change map
(Rk_*K)|_{X̄∩H} → Rk_{Y*}(K|_Y) is an isomorphism: the universal hyperplane section of X̄ is smooth over X̄, so Rk_*
commutes with pulling back to it, and generic base change over the space of hyperplanes gives the fibres. (b) By
the triangle j_!j^*K → K → i_*i^*K, (a) says that Rk_*j_!j^*K has zero stalks on X̄ ∩ H, that is
Rk_*j_!j^*K = j̄_!Rk′_*j^*K. (c) So H^i(X, j_!j^*K) = H_c^i(X̄ − H, Rk′_*j^*K). The variety X̄ − H is affine,
Rk′_* of a perverse sheaf is perverse because k′ is an affine open immersion (Artin), and compactly supported
cohomology of a perverse sheaf on an affine variety vanishes in negative degrees (Artin and duality). (d) Hence
H^i(X, j_!j^*K) = 0 for i < 0, which gives the restriction statement. No weights. ∎

### Smoothness (Bertini in characteristic p)

For X smooth of dimension D, closed in A^N, the pairs (x, H) with H containing the embedded tangent space at x form
a variety of dimension D + (N − D − 1) = N − 1, so the tangent hyperplanes are not dense in the dual space. For H
outside their closure the linear equation of H is non-zero on every tangent space at points of X ∩ H, so X ∩ H is
smooth of dimension D − 1. This is a dimension count, valid in every characteristic, because Γ is an immersion.
(Jouanolou's Bertini theorem for unramified maps is the reference, from memory.) The chart argument is as above. ✓
I suggest printing this count in the paper.

## SG-11. Re-proved

- Dimension 0: H_c⁰ is a sum of induced modules; the eigenvalues are the a-th roots of the local ones at a point of
  degree a, so the bound is the hypothesis. ✓
- Smooth affine of pure dimension d ≥ 1, lisse: degrees below d vanish; degree d is SG-09 with C the rank
  (an eigenvalue bound |β| ≤ q^{aw/2} at a point of degree a gives |Tr(F_{u,n})| ≤ rank·q^{nw/2}). For i ≥ d + 1
  take a smooth generic hyperplane section Y of X ⊂ A^s over a finite extension; A.5 for 𝓕^∨[d], dualized as in
  SG-08, gives H_c^{i−2}(Y)(−1) → H_c^i(X) surjective for i = d + 1 and bijective for i > d + 1; induction on the
  dimension bounds the source by q·q^{(w+i−2)/2}. A bound for F^e gives the bound for F. ✓
- General case: X reduced is a finite union of smooth affine connected locally closed strata on which the sheaf is
  lisse, ordered so that initial unions are open; exactness of H_c^i(U) → H_c^i(X) → H_c^i(Z) in the middle puts
  every eigenvalue of H_c^i(X) in one of the two outer groups. ✓

To add in the paper: that the Lefschetz property for this second hyperplane section is again A.5 (the case f = 0),
and that the induction hypothesis is the statement for all degrees in dimension d − 1 over every finite extension.

## SG-10. Re-proved

Upper bound from SG-11 (proper: H = H_c). The dual sheaf is pointwise pure of weight −w (this needs purity, not
only the upper bound, at every point). Poincaré duality pairs H^i(X, 𝓕) with H^{2d−i}(X, 𝓕^∨) into Q̄_ℓ(−d), so
every eigenvalue α of the first is q^d/β with β an eigenvalue of the second, |β| ≤ q^{(−w+2d−i)/2}, hence
|α| ≥ q^{(w+i)/2}. ✓ For the constant sheaf the hypothesis holds for every embedding ι, so every conjugate has the
absolute value q^{i/2}; algebraicity and independence of ℓ are the usual separate argument, as the text says.

The "shorter projective-only" paragraph is also right if the induction is run on purity in all degrees: degrees
below d by projective weak Lefschetz, degrees above d by duality from those, and the middle degree by SG-09 for the
affine complement with duality for the lower bound.

## Is this route in the literature?

- From what I know: **not in this form.** I did not search (budget; the brief asked for what I know).
- The idea is stated, in one footnote, in L. Alpöge's note of 20 Nov 2026 (footnote 3: the count qN = M^k + R on a
  path quadric, a definite sign from middle cohomology one off from that of M^k, a remainder of square-root quality
  by Parseval applied k times). The run's text works that footnote out. **The paper has to credit it.**
- Ingredients and nearest relatives, all from memory: tensor powers with Künneth (Deligne, Weil I, where the
  estimate comes from Lefschetz pencils, the monodromy theorem and Rankin's method); Weil II, Th. 3.3.1 (the
  statement proved here for compact support; there through curves and the Hadamard–de la Vallée-Poussin method);
  Laumon's proof by the Fourier transform (as in Kiehl–Weissauer, where a Plancherel formula for trace functions
  appears, in a different role, next to a positivity argument for an L-function with non-negative coefficients)
  and Katz's simplified proof of Weil II for curves (both keep a monodromy or Rankin step); Katz's use of families
  "f plus a general linear form" with this weak Lefschetz theorem for exponential sums (the article opened here).
  For curves there are Weil's proofs and the proof of Stepanov and Bombieri. For varieties of arbitrary dimension I
  know no earlier proof that uses neither a monodromy theorem nor Rankin's method or a variant of it.
