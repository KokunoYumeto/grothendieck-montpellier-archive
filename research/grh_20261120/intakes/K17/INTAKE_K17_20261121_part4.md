## 1. The DEKM question, decided

**Does the final return still claim the gap?** Yes, in the same form (K17.tex lines 1722-1760, "Retaining the rank-eight

**My check against arXiv:1910.11598v1.**
- **The convention of the complex.** §1.2.1 (p. 4): X_N has dimension d(N) = N(N+1)/2 − 1, i.e. it is the space of positive
  forms up to homothety; Σ_n is the set of cells of dimension n in X_N^*; a cell σ is the convex hull of the forms v̂, v ∈ m(σ), and
  its orientation is that of the vector space R(σ) they span. So a cell whose minimal vectors span R(σ) of dimension r (the
  perfection rank, Definition 2.1, p. 6) has dimension r − 1. Proposition 1.5 (p. 5) then gives H_{m−N+1}(Γ; St_N) ≅ H_m(Vor)
  modulo S_{N+1}. This convention is the one that fits the known cases: for N = 5 the cells run from dimension 4 (perfection rank
  5) to dimension 14 = d(5) (the three perfect forms), and Steinberg degree q = 10 = N(N−1)/2 sits at Voronoi degree 14.
- **The enumeration.** Table 3 (p. 14) counts cones by perfection rank r and lattice dimension n; its rows start at r = n (row
  n = 5 reads 2, 5, 10, 16, 23, 25, 23, 16 for r = 5, …, 12, the Elbaz-Vincent-Gangl-Soulé counts of Σ_4, …, Σ_11 for N = 5). For
  n = 8 it gives r = 8, …, 12 (13, 106, 783, 6167, 50645); for n = 9, r = 9, 10, 11 (44, 759, 13437) and "?" at 12; for n = 10,
  r = 10, 11 (283, 16062) and "?" at 12.
- **The indexing slip.** Table 4 (p. 15) lists these same numbers as Σ_n for n = 8, …, 12, with every Σ*_n = 0 (no
  orientation-preserving cell), and Proposition 4.4 calls the 13 rank-8 configurations of GL_8 "the 13 well-rounded cells of
  Σ_8"; Remark 3.2 likewise calls a family of s = n vectors a cell "of dimension n". Under the §1.2.1 convention these 13 cells
  have dimension 7, not 8. **Table 4 is shifted by one**: its column n holds the cells of dimension n − 1.
- **What the data support.** Since every enumerated cell reverses orientation, the chain groups vanish (mod S_2) in the
  enumerated dimensions, so H_m(Vor) = 0 there. With the correct dimensions this gives H_m(Vor_{GL_8}) = 0 for m ≤ 11, and
  H_m(Vor_{GL_9}) = H_m(Vor_{GL_10}) = 0 for m ≤ 10; that is, H_q(GL_8; St_8) = 0 for q ≤ 4, H_q(GL_9; St_9) = 0 for q ≤ 2,
  H_q(GL_10; St_10) = 0 for q ≤ 1 (mod S_{N+1}).
- **What is claimed.** Theorem 4.5 (p. 15) states H_k(Vor) = 0 mod S_2 for N = 8 and k ≤ 12, and for N = 9, 10 and k < 12. Its
  top cases, **(N = 8, k = 12), (N = 9, k = 11), (N = 10, k = 11)**, would need the cells of dimension 12 (perfection rank 13) of
  the GL_8 complex and of dimension 11 (perfection rank 12) of the GL_9 and GL_10 complexes. Table 3 has no rank-13 column and
  marks rank 12 for n = 9, 10 with "?". So these three cases, and the entries of Table 5 that rest on them (in Steinberg degrees:
  H_5(GL_8; St_8), H_3(GL_9; St_9), H_2(GL_10; St_10)), are **not supported by the enumeration the paper displays**. Corollary 5.1
  (p. 16, k = 8, …, 11) has the same problem at k = 11 for N = 9, 10.
- **Verdict.** **It is a gap, and the run states it correctly**: an off-by-one between the projective dimension of §1.2.1 and the
  perfection-rank indexing of Tables 3-4, Proposition 4.4 and Remark 3.2, which carries into the endpoint cases of Theorem 4.5 and
  Table 5. It is a gap in support, not a refutation: the three groups may well vanish. **It does not touch K_8(Z) = 0**
  (Theorem 6.4): total degree 9 needs only H_1(GL_8; St_8) and H_0(GL_9; St_9), both inside the supported range. Nor does it touch
  K17's final K_12 theorem, which no longer uses the Voronoi route.
- **Before anyone is told:** check the published version (JIMJ 2026) and the authors' data repository
  (github.com/elbazvip/Voronoi-complexes-dat, named on p. 14); either may contain the rank-13 cells for GL_8. If neither does, the
  note to the authors is a short one: the three endpoint cases and their locators, with the dimension count above.
