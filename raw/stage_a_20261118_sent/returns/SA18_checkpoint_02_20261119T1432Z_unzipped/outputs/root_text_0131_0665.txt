  526: \quad\text{all lie in exactly one hyperplane, but}\\
  527: &x^{(\beta_{n-1}+1)}\quad\text{is not in this hyperplane.}
  528: \end{array}
  529: \]
  530: Then $x^{(0)},x^{(\beta_0+1)},\ldots,x^{(\beta_{n-1}+1)}$
  531: do not lie in a hyperplane, hence
  532: $D_{0,\beta_0+1,\ldots,\beta_{n-1}+1}(x)\ne0$;
  533: and whenever $D_{\alpha_0,\alpha_1,\ldots,\alpha_n}(x)\ne0$, then
  534: \[
  535: \alpha_0\ge0,\quad\alpha_1\ge\beta_0+1,\quad
  536: \alpha_2\ge\beta_1+1,\ldots,\alpha_n\ge\beta_{n-1}+1.
  537: \]
  538: Therefore, the condition on $\ell$ is that:
  539: \[
  540: (*)\qquad\ell(d_{0,\beta_0+1,\ldots,\beta_{n-1}+1})\ge0.
  541: \]
  542: But it is easy to check that the set of all $\{\lambda\}$'s such that
  543: $\lambda_0\le\cdots\le\lambda_m$
  544: and $\displaystyle\sum_{i=0}^m\lambda_i=0$ is a convex set spanned by the particular set of
  545: $\{\lambda\}$'s given in the lemma. Therefore $(*)$ holds for some $\ell$ if and only
  546: if it holds for one of the extreme sets of $\{\lambda_i\}$.
  547: \uline{QED}
