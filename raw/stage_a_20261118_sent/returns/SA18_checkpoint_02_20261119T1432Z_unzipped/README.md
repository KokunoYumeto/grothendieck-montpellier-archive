# SA18 dossier working documentation

Source archive: `SA18_Varits_abliennes.zip`, supplied with the task. Extracted once to a sibling `sources` directory. The original attachments are excluded from checkpoints and final deliverables.

The source manifest records hashes and line counts. All locators refer to the supplied transcription files, counted from line 1; scan numbers refer to the original cote scans rather than printed manuscript pagination. `research/page_index.json` is a navigation aid, not a scientific classification.

Every indexed note requires a human-model reading of both note and passage. Scripts may navigate, validate, calculate and consolidate; they may not assign scientific verdicts by keywords.

Parallel source owners: agent16 (package16/47/54/44 and second pass); agent45 (package45, Codex45 and cotes48–52); agent46 (package46 and cotes46/53); root (package11/56 and Codex55/56). The root integrates and checks cross-source claims. The presence of cotes11,16,44 in package witnesses is documented explicitly; they are not silently relabelled as SA18 cotes.

Dates use 2026-11-19 as the status cutoff. A classification that no development was found is a bounded search result, not a claim that the literature contains none.
