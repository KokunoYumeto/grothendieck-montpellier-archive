# Reproducible programs and output

All Python programs executed for this child are saved in `code/`. They use only the Python standard library and, for primary PDF inspection, local Poppler commands.

1. `read_sources.py J156-3-01 ...` was run for each of the22 III–V folders. It writes the complete annotated transcript and complete note to `outputs/<folder>_read.txt`; these complete files also reproduce the subsequent targeted `sed`, `nl`, `rg` and `cat` readings. Where a tool response was truncated, the omitted passage was read separately before marking coverage complete.
2. `author_3.py`, `author_4.py`, `author_5.py` serialize the manually authored99 records. Their first output announces the count and pending literature fields; `finalize_claims.py` supplies all completed fates and the explicit later corrections. The intermediate JSON files remain for audit.
3. `computations.py` was executed, then improved to distinguish symbolic/manual checks from executed enumeration, and executed again. Both runs passed; the final `outputs/computations.json` is the authoritative finite certificate. The final printed report lists17 named model/calculation outputs,12 closed supports in the five-cycle model and6 in the seven-element model.
4. `fetch_primary.py` downloaded named public sources and records URL/status/hash in `*_fetch.json`. An initial version failed because `requests` was not installed; it was replaced with `urllib.request`, then rerun. Alexandroff requests failed403 or redirected. Birkhoff/Stong/Kochen–Specker and the two raw Lean files succeeded. Third-party full document bodies are research scratch and should be excluded from the delivered ZIP; fetch logs and curated locators are sufficient.
5. `render_sources.py stong1966 2 3 4` and `render_sources.py kochen_specker1967 1 2 4 5`, followed by pages7,8,9,10, generated PNGs for visual inspection. Commands and exit statuses are in the render logs. Only the pages explicitly listed in source_checks.md were used as source evidence.
6. `crossref_candidates.py` produces a locator aid. Its broad pattern also matches scan metadata and other nonreferences. Only the manually adjudicated entries in `links.tsv` are links; the candidate list is not a verdict table.
7. `finalize_claims.py`, `author_problems.py`, `author_tables.py`, `author_logs.py` generate the final JSON/TSV files from explicitly authored decisions. Each has a small saved output JSON. They do not infer mathematical statuses from keywords.

The web research calls are recorded as query groups in `search_log.tsv`, with raw returned evidence in the numbered search/open JSON files. Full downloaded books/papers and primary page images are not deliverables. Source excerpts in raw search output are evidence of access, not unqualified mathematical conclusions.
