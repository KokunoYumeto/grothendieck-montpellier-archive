# SA22 archive guide

The main deliverable is `SA22_dossier.md`. The user-requested master files are at the archive root. Additional evidence tables connect the records to searches, sources, computations and explicit refinements.

| File or directory | Purpose |
|---|---|
| SA22_dossier.md | English narrative, methodology, results and reconciled counts |
| SA22_entries.tsv | All287 source entries, one canonical item and verdict each |
| SA22_items.json |231 merged note items, original source versions where merged |
| SA22_claims.json |243 manuscript records plus11 explicitly labelled refinements |
| SA22_problems.json |97 canonical manuscript questions/programmes |
| SA22_readings.tsv |161 unresolved scan-inspection alarms; no ink decisions |
| SA22_links.tsv |55 links checked at their stated endpoints and verification level |
| SA22_project_leads.tsv |129 separate context leads with unavailable/unverified targets |
| SA22_directions.md |27 ranked, undeveloped tasks with provenance and first steps |
| SA22_references.bib |126 opened bibliographic records, with access scopes |
| SA22_source_evidence.tsv | Exact theorem locators, opened URLs and limitations |
| SA22_literature_searches.tsv | Recorded searches, opens and follow-up scope |
| SA22_claim_search_coverage.tsv | Search and reference coverage for every claim |
| SA22_refined_statements.json | Explicit targets for scope repairs/counterexample events |
| SA22_merges.tsv; SA22_reference_aliases.tsv | Canonicalization decisions |
| CHECK_EVENTS.tsv | Actual checks, with proof/computation/access distinctions |
| progress.log | UTC milestones and scheduled checkpoint history |
| programs/; outputs/ | Executed code and saved outputs/validation |
| parts/ | Detailed source-reading, proof, bibliography and independent review trails |
| research/ | Compact requests and source inventories; no external full texts |
| ARCHIVE_MANIFEST.json | Final archive inventory and SHA-256 hashes |

The archive omits the supplied inputs and previous checkpoint ZIPs. Restore the original attachments to inspect the unchanged diplomatic transcriptions. Source-part identifiers are retained as provenance; the master aliases define the current canonical records. The archive contains no additional unrequested download or standalone external full text.
