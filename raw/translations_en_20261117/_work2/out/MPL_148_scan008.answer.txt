\uline{Summary of the thesis} :

The design and implementation of a Relational Database Management System on a microcomputer, which we have christened ``LINAIRE'', is the subject of this thesis.

We emphasize three main points :

1. MULTI-LEVEL LOOP ; this is a data processing technique, making it possible to avoid the use of intermediate relations as results of relational operators, which would be particularly costly for a microcomputer possessing limited main memory.

2. INTERNAL STRUCTURE OF THE DATABASE ; it is multiple, in order to preserve performance as well as possible while offering in particular the possibility of speeding up the processing of the relational operator ``equi-join''.

3. The adaptation to a microcomputer of the manipulation language of QUERY-BY-EXAMPLE (a high-level, interactive, and tabular language).
