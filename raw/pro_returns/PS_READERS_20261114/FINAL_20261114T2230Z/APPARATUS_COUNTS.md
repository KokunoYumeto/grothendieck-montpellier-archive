# Apparatus counts

The current complete inventory contains **11,291 distinct variants** across **706 source pages**. Brown's translation is counted separately (134-2, archive sites 115–143); it is excluded from the main 134-2 row.

Counts come from `records/CHANGES_EN.tsv`, one row per maximal editorial operation. The row IDs agree with `records/BUILD_MANIFEST.json` and with the entry and inventory definitions in all four generated TeX forms. Nested layers within one wholly cancelled or replaced passage remain within that entry and are not counted a second time.

## Reproduction and provenance

Run `python scripts/build_apparatus_counts.py` from the project, or invoke that script by its path from another directory, after rebuilding the readers. It verifies the ledger against the build manifest and generated TeX IDs, then regenerates this report and the full division × kind × form table in `records/APPARATUS_COUNTS.tsv`. Structured totals and source hashes are in `records/APPARATUS_COUNTS.json`.

Change-ledger SHA-256: `97ac2be9486cd1c54c3970bc37c907cea1001057c82abfbb5bf09853850fdb35`.

The same command merges every `records/TYPESETTING_FIXES_*.tsv` schema into `records/TYPESETTING_FIXES.tsv`. The merged history preserves original rows, input-file hashes and data-row positions, including earlier generated repairs when later normalization empties their source file. Guide fixes and subsequently added normalization histories remain in scope. Its deduplication and input summary are in `records/TYPESETTING_FIXES_MERGE.json`.
