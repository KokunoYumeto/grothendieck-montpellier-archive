KTOWER checkpoint and final archive

The complete standalone paper is KTOWER/KTOWER.tex. All exact computations,
their source code, checks and dated registers are preserved as ZIP members.

Starting with checkpoint09, large numerical JSON members use the standard
ZIP LZMA compression method. This keeps the complete evidence inside the
file-transfer size limit without deleting files or changing their bytes.
All other members use ordinary DEFLATE compression. No older checkpoint
ZIP is nested in this one.

Python3's standard-library zipfile supports both methods. For example:

  python -m zipfile -e KTOWER_checkpoint_09.zip restored

7-Zip also supports both methods. Use the corresponding final/checkpoint
filename for a different archive. The PACKAGE_MANIFEST.json records the
SHA256 and uncompressed size of every member; verify_deliverable_zip.py
performs a full exact check using only Python's standard library.

This compression choice changes no theorem, certificate, input, output,
hash-bound proof review or original source file.
