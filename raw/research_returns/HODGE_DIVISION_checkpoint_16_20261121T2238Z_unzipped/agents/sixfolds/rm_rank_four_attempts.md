# Rank-four and weighted-power attempt record

This is an attempt log, not a theorem or independent check event.

## Rejected first nonsquare rank-four witness

Before freezing E840, the first proposed relations were

`(x²+yz, y², z², w²)`

with the same constant bivectors

`p=(1,1,0,0,1,1)`, `q=(1,−1,0,0,−1,1)`.

This candidate does have a rank-at-most-four bracket pencil and a nonprincipal rank-four image, but it does **not** survive the earlier scalar cross-minor condition. Its `(12,14)` minor is `−16xyzw`, which is nonzero in the length-sixteen quotient. It is therefore unsuitable as a strict witness beyond all previously derived scalar equations. No theorem or successful certificate was claimed for it.

The refined E840 witness replaces `yz` in the first relation by `yw`. In that algebra the extra `yz` term in the actual bracket tuple annihilates the whole bracket span, and all 36 ordered scalar cross minors vanish. The frozen main certificate checks this directly. The adjacent separate rejected-candidate checker verifies the failed first minor without altering the frozen E840 certificate.

## Weighted powers: unresolved matrix gate

For arbitrary formal parameters and powers `I=(u1^a1,…,u4^a4)` with all `ai≥2`, write `vi=ui^(ai−1)`. The brackets have terms `ai aj vi vj` times units or functions. Products of complementary pairs lie in the one-dimensional top socle, so the constant support/Plücker reductions used for squares retain some force. The missing universal statement is a weighted analogue of the four-edge square-matrix lemma: does annihilation of the cokernel by four distinct `vi vj` force a square matrix to be invertible? No proof or counterexample has been obtained.

Two tempting reductions are invalid and are not used:

1. Passing to the quotient `ui²=0` kills `vi` when `ai>2`; it loses the relevant bracket equations.
2. The subalgebra generated by the `vi` is a four-variable square algebra, but the larger power algebra is generally not free over it. Multiplication by `vi` has rank `dim(A)/ai`; on a free module over the square algebra it would have rank `dim(A)/2`. Thus freeness fails whenever `ai>2`. A coefficient projection to that subalgebra is not a ring homomorphism and does not preserve arbitrary matrix equations.

No deformation, Ext group, or matrix factorization has been base changed using either reduction. Small exploratory matrix searches do not establish this universal gate and are not counted as proof. E840 instead treats the independently justified equality case for regular quadratic initial forms.
