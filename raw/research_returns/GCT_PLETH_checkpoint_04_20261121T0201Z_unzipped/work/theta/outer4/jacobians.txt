         Consider a curve of genus one over a field K in one of three explicit forms: a
      double cover of P1 , a plane cubic, or a space quartic. For each form, a certain
      syzygy from classical invariant theory gives the curve’s jacobian in Weierstrass
      form and the covering map to its jacobian induced by the K-rational divisor
      at infinity. We give a unified account of all three cases.




                               1. INTRODUCTION
   Let C be a complete, non-singular curve of genus one over a field K. Let
n be the smallest positive integer such that C has a K-rational divisor D
of degree n. By the Riemann–Roch theorem, the linear system associated
with D gives a map φD : C → Pn−1  K    which embeds C as a curve of degree
n if n ≥ 3, and is a map to P1K of degree 2 if n = 2.
   The case n = 1 is distinguished, since in that case C has a rational point,
and may be given the structure of an elliptic curve. An elliptic curve over
K is a pair (E, O) , where E is a curve over K of genus one and O ∈ E(K).
Such a curve has a Weierstrass equation, which, if the characteristic of K
is not 2 or 3, may be written in the form

                                  ζ 2 = 4ξ 3 − g2 ξ − g3 .                                (1)

Given a curve C of genus one, there is an associated elliptic curve (E, O),
where E is the jacobian of C, Jac(C), and O is the point on E corresponding
to the trivial divisor class.
  In general, we can define a K-rational map of degree n2

                             jD : C → Jac(C)
                                  Q 7→ class of nQ − D.


 Explicit equations for the map jD are useful in performing explicit n-
descents on elliptic curves ([3], [9]) and in studying the Sharafevich–Tate
group ([10], [7], [4], [8]).
  In this paper we will show how formulas from classical invariant theory
give explicit Weierstrass equations for the jacobian of C and for the map
jD in the cases n = 2, 3, 4. Partial results along these lines already exist
in the literature; however, we know of no comprehensive reference with
proofs for all cases, particularly for the case n = 4. Moreover, it seems
useful for computational purposes to gather all the formulas in one place.

                   2. STANDARD FORMS FOR C
  From now on we assume char(K) 6= 2, 3. Let C, n, and D be as in the
previous section. A general reference for linear systems and the associated
embeddings is [6, pp. 294–296].
  If n = 1, any effective rational divisor linearly equivalent to D (they exist
because |D| is nonempty) is a rational point O. Then (C, O) is an elliptic
curve, and can be given in Weierstrass form. (In fact, the Weierstrass form
can be obtained by considering the embedding given by |6O|.)
  If n = 2, the map φD is a degree 2 map C → P1K , tamely ramified at
four points by the Hurwitz formula [6, p. 301]. Thus we can represent C
as a singular curve in P2K with projective equation

           C : Z 2 Y 2 = U (X, Y ),     (U a binary quartic form).             (2)

  For n ≥ 3, the divisor D is very ample [6, Corollary 3.2, p. 308], and
thus the map φD embeds C as a degree n curve in Pn−1      K . We repeatedly
use the following fact: if C and C 0 are projective curves of the same degree
(possibly reducible), and if C ⊂ C 0 , then C = C 0 . Indeed, C 0 = C ∪ C 00 for
some projective curve C 00 not contained in C, and the intersection number
between C 00 and a hyperplane must be 0, hence C 00 = ∅.
  For n = 3, the linear system |3D| has dimension 9 by Riemann–Roch,
yet the space of cubic forms on P2K has dimension 10, and thus there is a
non-zero cubic form that vanishes on C. Hence C is contained in the zero
locus of this form, and since they both have the same degree, namely 3,
they must be equal. Thus C has equation:

            C : U (X, Y, Z) = 0,       (U an ternary cubic form).              (3)

   For n = 4, the linear system |2D| has dimension 4 by Riemann–Roch,
yet the space of quadratic forms on P3K has dimension 6, and thus there
are two linearly independent quadratic forms that vanish on C. Hence C
is contained in the intersection of two quadric hypersurfaces, and since it
has the same degree as the intersection, namely 4, it must be the equal to
4          ! Please write \authorrunninghead{<Author Name(s)>} in file !


it. So C has equations:

    C : U (X, Y, Z, W ) = V (X, Y, Z, W ) = 0,
                                      (U, V quaternary quadratic forms). (4)

  From now on, we suppose C to be given in one of the forms (2), (3), or
(4), and we let D be the intersection of C with the hyperplane at infinity.
Our problem now is to determine formulas for the coefficients g2 and g3
of a Weierstrass model for JC , and to determine equations for the map
φD : C → JC .


               3. STATEMENT OF MAIN THEOREM
   We recall some basic terminology from classical invariant theory. Con-
sider the vector space V composed of k-tuples of homogeneous forms of
degree d in n variables X1 , . . . , Xn . Then GLn (K) acts on V : for F =
(F1 , F2 , . . . , Fk ) ∈ V , g ∈ GLn (K), we define gF by

                (gF )(X) = F (gX),       X = (X1 , X2 , . . . , Xn ).

If I is a polynomial on V (that is, a polynomial in the coefficients of the
forms F1 , . . . , Fk ), we define g ∗ I by g ∗ I(F ) = I(gF ), F ∈ V . An invariant
is such a polynomial satisfying

                                 g ∗ I = det(g)p I

for some non-negative integer p. It is necessarily homogeneous in the coef-
ficients of F . A covariant is a homogeneous form U (X) whose coefficients
are homogeneous polynomials in the coefficients of F such that

                          (g ∗ U )(X) = det(g)p U (gX).

Here g ∗ U denotes the form whose coefficients are transformed by g ∗ . In
particular, the forms F1 , . . . , Fk are themselves covariants.
   A program of classical invariant theory was to determine a set of gener-
ators (fundamental covariants) and relations (syzygies) for the algebra of
covariants for a given n, k, and d. We quote results from the nineteenth
century literature giving the fundamental covariants and syzygies for the
three cases relevant to our problem: binary quartic forms, ternary cubic
forms, and pairs of quaternary quadratic forms. In each case we show
how the syzygy gives a map from our curve C to an elliptic curve E in
Weierstrass form. In what follows, we denote partial derivatives of a form
U (X, Y, Z) by UX , UXY , etc.

         4. RECOLLECTIONS ON ELLIPTIC CURVES
  Let C be a curve of genus one. If L is any field extension of K such
that C has an L-rational point O, then we may regard (C, O) as an elliptic
curve over L. There is an isomorphism, defined over L,

                          iO : C ≃ Jac(C)
                               P 7→ class of P − O


 This gives C the structure of an algebraic group, with O as the identity
element. Furthermore, if φ : (C, O) → (C 0 , O0 ) is a morphism of elliptic
curves, then it is a homomorphism for the group structure. In fact, if
φ∗ : Jac(C) → Jac(C 0 ) is the map on jacobians induced by φ, then φ =
i−1
 O 0 ◦ φ∗ ◦ iO .
   Given an elliptic curve (E, O), defined over a field K, we consider the
set WC(E) of isomorphism classes of pairs (C, i), where C is a genus one
curve over K and i is an isomorphism of elliptic curves Jac(C) ≃ E, defined
over K. Two pairs (C, i) and (C 0 , i0 ) are isomorphic if there exists a map
φ : C → C 0 defined over K such that the following diagram commutes:

                                        φ∗
                           Jac(C) ←−−−− Jac(C 0 )
                                            
                             iy≃          i0 y≃

                           E               E
  The set WC(E) contains a distinguished element, namely (E, i−1  O ). In
fact, WC(E) can be given a group structure in which this element becomes

the identity element; the resulting group is called the Weil–Châtelet group.
One can reconcile this definition of the Weil–Châtelet group with the more
traditional definition in terms of principle homogenous spaces by noting
that C has a natural structure of principle homogeneous space over its
jacobian.
  Definition 4.1.  Let (C, i) and (C 0 , i0 ) be elements of WC(E). We say
that a map φ : C → C 0 defined over K is an n-covering if the following
diagram commutes:



                                      φ∗
                           Jac(C) −−−−→ Jac(C 0 )
                                            
                             iy≃          i0 y≃
                                       n
                             E    −−−−→       E
  The simplest example of an n-covering is the multiplication-by-n map
on E itself. The kernel of this map is the group E[n] of n-torsion points on
E, which has n2 points defined over K if char(K) does not divide n, which
we assume from now on.
   Definition 4.2.       On a curve C of genus one over K, an n-torsion
packet, Tn , is a set of n2 points on C such that given P, Q ∈ Tn , nP − nQ
is the divisor of a function f in K(C).


  Lemma 4.1. Let (E, O) be an elliptic curve. If Tn is an n-torsion packet
on E and if O ∈ Tn , then T = E[n].


  Proof. It follows directly from the definition of the group structure on
E that Tn is contained in E[n], and it has the same cardinality as E[n].

  Lemma 4.2. Let n be a positive integer prime to the characteristic of
K. Given a morphism of elliptic curves φ : E → E 0 , defined over K, such
that Ker(φ) = E[n], there exists an isomorphism E 0 ≃ E defined over K
such that the following diagram commutes:

                                       φ
                                E −−−−→ E 0
                                       
                                y=      y≃
                                       n
                                E −−−−→ E

   Proof. The morphism φ induces an injective map of function fields
K(E 0 ) → K(E). Since ker φ = E[n], the image of this map is the subfield L
of of K(E) fixed by E[n]. The multiplication-by-n map induces an isomor-
phism between L and K(E); composing this with φ we get an isomorphism
of function fields K(E 0 ) ≃ K(E). The corresponding isomorphism of curves
has the desired properties.
  The following key proposition was noted in [9] without proof; we give a
brief proof here.

  Proposition 4.1. Let E be an elliptic curve over K and WC(E) its
Weil–Châtelet group. Let (C 0 , i0 ) be an element of WC(E) and C a genus
one curve over K. If we have a map φ : C → C 0 defined over K such that
there exists a point Q ∈ C 0 with φ−1 (Q) an n-torsion packet, then there
exists an isomorphism i : Jac(C) ≃ E defined over K such that φ : (C, i) →
(C 0 , i0 ) becomes an n-covering.


   Proof. Let O ∈ φ−1 (Q). Then φ : (C, O) → (C 0 , Q) is a morphism of el-
liptic curves defined over K. By Lemma 4.1, the kernel of φ is C[n]. Hence
the kernel of φ∗ : Jac(C) → Jac(C 0 ) is Jac(C)[n], so by Lemma 4.2 there ex-
ists an isomorphism j : Jac(C 0 ) → Jac(C), defined over K, so that j ◦ φ∗ =
[n]. Define i : Jac(C) → E by i = i0 ◦ j −1 . Then i0 ◦ φ∗ = i ◦ j ◦ φ∗ = i ◦ [n].
Since i is a group homomorphism, i◦[n] = [n]◦i, hence i0 ◦φ∗ = [n]◦i, which
makes φ into an n-covering.


                  5. PROOF OF MAIN THEOREM
   Denote the point [0, 1, 0] on E by ∞. In each case we show that ψ −1 (∞)
is an n-torsion packet, where ψ : C → E is defined by equations (7), (13),
and (16) respectively. The main theorem then follows from Proposition 4.1.
                            5.1. Case n = 2
   From (7) we see that ψ −1 (∞) comprises the points [X, Y, 0] where [X, Y ]
is a root of the binary quartic U (X, Y ). Those 4 points compose a 2-
torsion packet: if P = [X1 , Y1 , 0] and Q = [X2 , Y2 , 0] are two of them, the
rational function (Y1 X − X1 Y )/(Y2 X − X2 Y ) has divisor 2P − 2Q. By
Proposition 4.1, E must be JC .
                            5.2. Case n = 3
                              −1
  From (13) we see that ψ (∞) comprises those points on (3) where H
vanishes. The covariant H is the so-called Hessian, and its zero locus
intersects C in the set of 9 flex points on C (see [14, p. 145, Art. 173]).
12           ! Please write \authorrunninghead{<Author Name(s)>} in file !


Given two such points P and Q, there are lines M = 0, N = 0 meeting C
only at P and Q, respectively; hence the divisor of M/N is 3P − 3Q. Thus
ψ −1 (∞) is a 3-torsion packet on C.
                            5.3. Case n = 4
  From (15) we see that ψ −1 (∞) comprises those points on (4) where J
vanishes. It is shown in [2] that the zero locus of J intersects C in the
set of 16 hyperosculation points on C, that is, the set of points where the
osculating plane meets C to order 4. (See also [13, Art. 362, p. 378]). By
the same arguments as in the case n = 3, the set of 16 hyperosculation
points is a 4-torsion packet.
