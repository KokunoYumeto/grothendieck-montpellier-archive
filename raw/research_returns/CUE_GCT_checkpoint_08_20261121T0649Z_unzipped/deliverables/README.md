# CUE_GCT research package

This is a continuing research package. The unrestricted polynomial ROABP hitting-set and asymptotic GCT requests remain unresolved; proved restricted results and their exact gates are distinguished in the manuscript and registers.

## Contents

- CUE_GCT.tex: self-contained assembled paper, with checked results, unchecked targets, Grothendieck dictionary, and APA-style source entries with exact locators.
- QUESTIONS.tsv: normalized question states and current gates.
- LEDGER.md: actual dated progress and schedule.
- CHECK_EVENTS.tsv: actual proof, dependency and finite-computation checks, with model/run attribution.
- TRANSCRIPTION_NOTES.tsv: mathematically required readings, with original-image limitations.
- IMPLICATIONS.md: what changes and what remains open.
- work/: modular manuscript sources, exact certificate generators, finite integer/modular certificates, independent reviews, source registers and attempted constructions.

The attached source archive was unpacked once. Its hash manifest is work/SOURCE_MANIFEST.tsv. To continue, restore this package beside the supplied attachments; the sources/ directory, when present, is an unchanged copy of their extracted contents. Reassemble with `python3 work/assemble.py`. Individual computation scripts state their assumptions and output scope. The final paper's prose proofs and the finite certificates are complementary.

No prior checkpoint ZIP is included in this package. Checkpoint names are unique and are never overwritten.
