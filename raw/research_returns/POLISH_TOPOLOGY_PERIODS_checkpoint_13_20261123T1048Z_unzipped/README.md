# Third-sweep research preparation

This is a live research deliverable for seven papers on Grothendieck's
Montpellier manuscripts. It is not a claim that all 1,027 inherited
assertions have been newly verified. The papers are standalone LaTeX projects
with PDFs; their current proof and literature gates are recorded in LEDGER.md
and the topic notes.

Start with LEDGER.md, REGISTER.tsv and CHECK_EVENTS.tsv. INHERITED_CHECK_EVENTS.tsv
preserves old evidence separately. STATEMENT_TEXT.tsv supplies complete
inherited statement text where the source title is too short. CROSSWALK.tsv
maps the developing manuscripts back to those records. The current workbench
is a format-1 preparation awaiting registry numbers and an actual deposit.

No unchanged attachment file and no third-party source PDF, scan, or extracted
text is included. Bibliographic citations, source addresses, hashes, and
locators document sources that can be fetched again. No messages to authors
and no repository pushes have been made.

All manuscripts have empty author lines. Our text is dedicated under CC0 1.0.
The mathematical checks were performed by models with the provenance and
scope stated in the records; no human has checked these papers.
