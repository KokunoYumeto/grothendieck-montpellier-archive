# Algebraic cycles and motives workbench

This working version contains three standalone papers on bounded algebraic cycles, obstructions, and an effective one-prime criterion. The principal Gaussian eightfold detector remains open. Start with Paper C's introduction and the root QUESTIONS.tsv for the exact state.

- work/UNFILED-A/v2/paper: the revised bounded-cycle paper, with the cyclic-four Jacobian calculation.
- work/UNFILED-B/v2/paper: the revised obstruction paper, with ordinary Mumford reduction counts.
- work/UNFILED-C/v1/paper: the effective one-prime criterion and its explicit remaining hypotheses.

Format1 statement tags and check events preserve prior identities. New statement tags continue after UNFILED.113. Every paper contains its mathematical argument.
