# Grothendieck topology, periods and categories: preparation workbench

This folder prepares seven works for three field repositories. Each paper is
self-contained; checks and certificates supply additional evidence. The records
distinguish inherited claims from checks made during this preparation.

**Status: research in progress.** Do not treat a compiled PDF as a certificate
that every inherited result has been checked. Read the top-level LEDGER and
the scope of each CHECK_EVENTS row.

The directory structure follows workbench format 1 except that PAPER-01 through
PAPER-07 are provisional names. The registry assigns WB numbers at filing; no
number, public commit or completed deposit has been invented. A filing step
must allocate permanent tags, replace the registry address, insert the version
identity in the paper, rebuild, and seal the manifest. DEPOSITED.md is created
only after the actual deposit. Each current MANIFEST covers the draft files
except the manifest itself.

Field homes:
- homotopy-and-categories-workbench: Papers 1, 2, 5, 6, 7.
- algebraic-cycles-and-motives-workbench: Paper 3.
- schemes-and-moduli-workbench: Paper 4.

Only original and adapted project work is included. External papers and scans
are referenced, hashed where retrieved, and not copied. Existing-source reruns
can require the original attachment; fresh programs and outputs are included.
No repository has been pushed or publicly deposited by this preparation.
