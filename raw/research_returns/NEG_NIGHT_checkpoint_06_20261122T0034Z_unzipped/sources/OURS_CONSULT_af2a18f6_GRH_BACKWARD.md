**Conventions.**
- X = Spec A for a finitely generated Z-algebra A = Z[x₁..x_n]/(f₁..f_m), of encoding size N.
- π: X → Spec Z is its structure map.
- A finite étale Galois cover Y → Spec Z[1/S] with group G has a Frobenius conjugacy class Frob_p ⊂ G at every

**Theorem AG-1 (Koiran, as a statement on the image of Spec A → Spec Z).** By Chevalley the image π(X) is
constructible. So it either omits the generic point, and is then a finite set of closed points, or contains it, and is
then cofinite.
- (i) **Unconditional.** If X_Q = ∅ (the generic point is not in the image), then π(X) is contained in the closed
  points dividing one integer a ≠ 0 with log a ≤ 2^{poly(N)}. So #π(X) ≤ 2^{poly(N)}. This is the arithmetic
  Nullstellensatz, Koiran Thm 5.
- (ii) **[M].** If X_Q ≠ ∅, choose a closed point Spec E ∈ X_Q with [E:Q] = d and log|D_E| ≤ 2^{poly(N)} (Koiran
  Thms 4, 7). Then #{p ≤ x : p ∈ π(X)} ≥ (1/d)(Li x − O(√x log(|D_E| x^d) + d√x + log|D_E|)), because every degree-one
  closed point of the closure of Spec E in X, over p ∤ (bad integers), maps to p.
- **Consequence.** At x = 2^{P(N)} the two cases are separated, so "the generic point of Spec Z lies in π(X)" is in
  AM ⊆ Π₂^P.

## Q2. Checking the note's §12 (Koiran) and §14 (effective Chebotarev)

**§12, Koiran.** The reading is right in substance. Five corrections of detail:
1. **The analytic input is not "effective Chebotarev" in a Galois closure.** It is the prime-ideal theorem for the
   single field E generated by one bounded solution, i.e. Lagarias-Odlyzko Thm 1.1 for E/E, under RH for ζ_E. The
   count used is of degree-one primes of E: at most d prime ideals lie over each p, so the number of p ≤ x at which S is
   soluble mod p is ≥ (1/d)(Li x − O(√x log(D_E x^d) + d√x + log D_E)) (CX_GRH CX-K01, confirmed). Galois closures would
   multiply the degree factorially; they are not needed.
2. **"Few" is unconditional.** For an inconsistent system, the arithmetic Nullstellensatz gives an integer certificate
   a ≠ 0 with log a ≤ 2^{poly(N)}, and S is soluble mod p only for p | a. So there are at most 2^{poly(N)} such primes
   (Koiran Thm 5). GRH is used only on the consistent side.
3. **Why GRH is needed.** It is because of the scale, not the density. Both counts live below x = 2^{P(N)}, and the
   primes there have polynomial bit length. The unconditional prime-ideal theorem (Lagarias-Odlyzko Thm 1.3) is valid
   only for log x ≥ 10 d (log D_E)², with d and log D_E of size 2^{poly(N)}. That forces primes of exponential bit
   length, which the verifier cannot use. So GRH does not lower a density threshold; it brings the *range of validity*
   of the count down to polynomial-size primes.
4. **"Read off" means approximate counting.** The AM protocol does not decide support prime by prime. It distinguishes
   the size of {p ≤ x : S soluble mod p} between ≥ (1/d) Li x − error and ≤ 2^{poly(N)}, by public-coin hashing
   (Goldwasser-Sipser). In the note's terms: the B-coordinate over C is read off from the *cardinality* of the set of
   primes with nonempty fibre, and GRH keeps that cardinality's error below the gap.
5. **Scope.** In §12 and in §14 item 1, write "[M], with [A] for the bounded abelian-witness promise (CX-K03)". The
   restriction to M is forced by the case x³ − 2 (CX-K04).

The sentence "zeros off the line would be the cancellation" is acceptable as a reading: an off-line zero ρ adds a term
of size x^{Re ρ}/(\|ρ\| d) to the count, which at this scale can swamp the main term.

**§14, effective Chebotarev as "no unsupported small window".** Right for the windows [2, X], with three
qualifications:
1. **The statement that holds** (under RH for ζ_L, L/Q Galois): for every conjugacy class C, the set of unramified
   p ≤ X with Frob_p ∈ C is nonempty ("supported") once X ≥ (4 log d_L + 2.5 n_L + 5)² (Bach-Sorenson Thm 5.1), and it
   has the expected density with error O(√X log(d_L X^{n_L})) (Lagarias-Odlyzko Thm 1.1). That is "no unsupported
   *initial* window of length ≫ (log d_L)²".
2. **Not an arbitrary short window [x, x+h] far out.** Under RH one gets a prime in [x, x + c√x log x] (Cramér type),
   and for a Chebotarev class the window must also exceed √x log(d_L x^{n_L}) times |G|/|C|. "Every small window is
   supported" is false; it holds for initial windows and for long enough windows of length ≫ √x · log.
3. **Scope.** [A] only for L/Q abelian. For non-abelian L it is [M], whatever the abelianness of L over an intermediate
   K (ALPOGE_BRIDGES CC-C01).

The constants in §14 item 1 are right: least quadratic nonresidue < 2 log² p (Bach) and < log² p for p ≥ 5 (LLS); least
prime in a progression ≤ (φ(q) log q)² (LLS). For generating (Z/N)^× by primes, the coprime theorem has coefficient 3,
not 2 (AN_GRH T01).

## Q3. Alpöge's sign mechanism with G(R)-semimodule coefficients (prompt 54, item 10(a))

**What the mechanism is.** I take it as described in Alpöge's note (steps 3 and 5) and as completed by HODGE_SIGN
(SG-08 to SG-11; Hexagon register H01):
- on U^k, cut by a generic hypersurface built from a bilinear "path form";
- generic weak Lefschetz (Katz, ACT, Cor 3.4.1, weight-free) puts all the cohomology of the cut in one degree d;
- so the trace-formula remainder is (−1)^d times an *effective* class [K_k] + H_c^d(U, F)^{⊗k} in K₀ of Frobenius
  modules;
- Parseval, applied k times, bounds the remainder at square-root size, with a loss independent of k;
- the tensor-power trick, together with "opposite signs forbid cancellation of inverse roots", gives purity.

**Where it uses subtraction.**
1. **The Grothendieck-Lefschetz trace formula** Σ_x Tr(Frob_x | F_x) = Σ_i (−1)^i Tr(Frob | H^i_c). This is an alternating
   sum in K₀ and needs additive inverses in the ring where the traces live.
   - The sign-only move is precisely to make this sum sign-definite: after generic weak Lefschetz only H^d survives, so
     the alternating sum becomes (−1)^d × (a trace on an effective class).
   - From then on the argument lives in the *effective cone* K₀⁺ (a semiring), up to one global sign.
   - **[proved here, as a reading of the cited argument]**
2. **Parseval** (orthogonality of additive characters, Σ_t ψ(at) = q·[a = 0]): genuine square-root cancellation in
   Q̄_ℓ ⊂ C. This needs subtraction (cancellation of roots of unity), and cannot be done in a semiring without additive
   inverses.
3. **The positivity step** (Σ_i |α_i|^{2k} ≥ |α_max|^{2k}, and |Σ_i α_i^k|² = Σ_{i,j} (α_i ᾱ_j)^k on F ⊗ F̄) needs only
   the semiring R_{≥0} and absolute values. It is subtraction-free, but it needs an *archimedean absolute value* on the
   coefficients, via an embedding ι: Q̄_ℓ → C.

**With G(R)-coefficients.** By the note's §3.1 (Clifford), a G(R)-semimodule is a diagram M = (M_l)_{l ∈ L} of
R-modules over a join-semilattice L, with structure maps T_{l,l′}. For a *fixed* skeleton L, an étale sheaf of
G(R)-semimodules with skeleton L is a functor L → Sh(X, R-Mod). That is a sheaf of modules over the incidence algebra
R[L], an abelian category, so cohomology is ordinary: H^i_c(X, M) is the diagram (H^i_c(X, M_l))_l with the induced
maps. **[proved here: the functor-category description is standard; L is fixed and finite]**

Hence the sign mechanism runs, but **only fibre by fibre**:
- **Fibrewise.** Take R = Q̄_ℓ, or a subring with an embedding ι into C. If each M_l is pointwise ι-pure of weight w,
  the argument gives that H^i_c(X, M_l) has ι-weights ≤ i + w, and is pure of weight i + w when X is proper and smooth
  and M_l is lisse. That is Deligne's Weil I Thm 1.6 and Weil II Thm 3.3.1, by the sign-only route. **[standard
  conclusion; the route is HODGE_SIGN SG-08-SG-11, at statement level in my files]** The structure maps are Frobenius-
  equivariant, so the diagram of cohomologies is a diagram of mixed modules of weights ≤ i + w. Purity is inherited
  by the diagram, because each vertex is pure. No further argument is needed: L is finite, and a filtration by order
  ideals of L has pure graded pieces.
- **On the skeleton.** The skeleton L carries no additive inverses (idempotent join, 1 + 1 = 1) and no absolute value,
  so steps 1-3 have nothing to act on. What Frobenius does there is a permutation of a finite constructible
  semilattice. If L is the skeleton of a constructible sheaf it is finite, so Frobenius has finite order on it, and
  every "eigenvalue" one could attach (on the linearization Q̄_ℓ[L]) is a root of unity: **weight 0, an Artin
  (finite-monodromy) object.** This is the same statement as CX_GRH CX-G06 (finite monodromy ⇒ pointwise weight 0,
  confirmed). On the skeleton the "Riemann hypothesis" is the triviality that a permutation has eigenvalues of absolute
  value 1. **[proved here]**
- **Where a genuinely semiring version would have to act.** The only point where G(R)'s extra element τ could matter is
  the passage from counts to support, i.e. whether a fibre is τ (empty, unsupported) or not. In the trace formula that
  passage is a cardinality, a number in N, so it is already subtraction-free. The sign mechanism does not touch it.
  - Conversely, the sign mechanism's substantive core (step 2, Parseval) is not subtraction-free, and cannot be made so
    over B or over G(R)'s τ-coordinate.
  - So the answer to item 10(a) is: the mechanism runs with G(R)-semimodule coefficients, fibre by fibre, because the
    fibres are ordinary R-modules. G(R) adds a weight-0 permutation datum on the skeleton and nothing else. The
    subtraction-free part of the argument (steps 1 and 3) is the move from K₀ to its effective cone K₀⁺. That cone,
    not G(R), is the natural semiring in which the argument already lives.
