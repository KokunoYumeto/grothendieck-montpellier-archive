Theorem 1.4 (Proved: exact Boolean test) . For any orthoset E, finite or infinite, Σ(E) is
Boolean if and only if
x ⁄⊥ y =⇒ (∃z ∈ E) N (x) ∪ N (y) ⊆ N (z). (2)
The quantifier includes x = y. For a comparability disjoncteur this is the required necessary and
sufficient condition on the order of L, using NL in place of N . For finite L, it is a direct test on
triples of points and their neighbourhoods; no lattice enumeration is required.
Proof. The inclusion in (2) says precisely z ∈ cl{x} ∩ cl{y}. Moreover x ⊥ y if and only if the
two singleton closures are orthogonal. In a Boolean algebra disjoint elements are orthogonal,
so nonorthogonality forces a nonempty intersection of these closed sets, proving necessity. For
sufficiency, if closed A, B are not orthogonal, take x ∈ A, y ∈ B with x ⁄⊥ y. The specified z
belongs to A ∩ B. Thus for closed sets, zero meet implies orthogonality. We verify the purely
lattice-theoretic last step. In any ortholattice with this property, a ≤ b and b ∧ a⊥ = 0 imply
b ≤ a; hence the lattice is orthomodular. To see this last criterion directly, set c = a ∨ (b ∧ a⊥);
then b ∧ c⊥ = 0 , so b = c. Now let d = ( a ∧ c) ∨ (b ∧ c) and e = ( a ∨ b) ∧ c. We have d ≤ e.
Put t = e ∧ d⊥. Both t ∧ a and t ∧ b are zero, so t ≤ a⊥ ∧ b⊥ = (a ∨ b)⊥; also t ≤ a ∨ b. Hence
t = 0, and orthomodularity gives e = d. This is distributivity. The converse implication from
orthogonality to zero meet was already established in Proposition 1.2.
1.2 The interval magasin and the false Sumner equivalence
Definition 1.5 (Checked: the interval magasin) . For any poset L let
M (L) = {Pa : a ∈ L} ∐ {Iab : a < b in L}.
The endpoint set is δ(Pa) = {a} and δ(Iab) = {a, b}. The positional order is
U < p V ⇐ ⇒ U ⁄= V and (∀u ∈ δ(U ), v ∈ δ(V )) u ≤ v.
Primitive internal disjunction is strict comparability for this order. Incidence has only Pa, Pb ◁ Iab
in addition to identities. Interior refinement, written ρ, has identities and
PxρIab ⇐ ⇒ a < x < b, I cdρIab ⇐ ⇒ a ≤ c < d ≤ b.
A prefigure is a positional chain. A figure must additionally contain the endpoints of each of its
intervals. Thus a singleton interval is a prefigure and is not a figure. These are the data of 156-8,
scans 90–127 and 156-9, scans 5–7, with the distinction required by the latter page restored.
Proposition 1.6 (Proved: the interval construction for every poset) . For every poset L, the
relations of Definition 1.5 satisfy strong Mag 1–4. The magasin M (L) is faithful if and only if L
is a chain, including the empty and one-point cases. In the full atlas its figures are precisely the
positional chains closed under adjoining interval endpoints. Restricting the atlas to finite figures
gives exactly the finite such chains; no local finiteness or density of L is needed.
Proof. We check the strong primed formulation in Theorem 2.7, rather than invoking an unverified
general construction. Incidence is a partial order since its only strict relations run from a point to
an interval having that endpoint. Interior refinement ρ is a partial order: interval refinement is
containment of the two ordered endpoints, and PxρIcdρIab gives a ≤ c < x < d ≤ b, hence PxρIab.
