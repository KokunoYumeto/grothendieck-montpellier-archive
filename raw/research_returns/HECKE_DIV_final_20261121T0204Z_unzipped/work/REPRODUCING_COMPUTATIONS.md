Run the commands below from the project root, the directory containing `work/` (and `deliverables/` in the historical workspace). In the original workspace this directory is `/workspace/scratch/67cce309ceac`; in the final archive it is the directory containing the flattened `HECKE_DIV.tex`. ```sh


Most scripts write their `.json` output next to their source and also print a summary or the complete output. Rerunning them overwrites those output files. **`integral_seeds.py` is the exception: it prints JSON but does not save a file itself.** Its command below supplies the necessary redirection. These calculations certify finite algebraic assertions under the indicated definitions and transcribed inputs. It is not an additional independent implementation, and those repeated executions must not be counted as additional independent checks.

`severn_quantitative.py` is independent of those preceding output files. ## 4. Relative costs and existing timing records

The scripts involve small fixed polynomial problems or a finite orbit of only `756` vectors; their large resulting integers should not be confused with a search through cycles or a search through the whole group by enumeration. Costs below are qualitative unless an actual time was recorded.

| Group | Relative cost and practical observation |
|---|---|
| Integer-pair independent projector checks, integral seeds, independent Markman arithmetic | Lightest. Standard-library calculations on small coefficient lists or polynomial dictionaries. No fresh benchmark was run for this guide. |
| Projector production, Gotzmann arithmetic, Markman GRR arithmetic, small Severn quantitative arithmetic | Small exact symbolic tasks. SymPy import, expansion, polynomial inversion, and factorization are the main costs; no large geometric enumeration occurs. |
| Printed-block check | More symbolic linear algebra: exact `4×4` determinants, minors, and rational span rank. Its result is already saved; no new timing was collected here. |
| Monodromy reconstruction | Exact elimination on the fixed cocycle matrices and seventeen twists. The original check note records approximately **0.6 seconds** in this workspace. |
| Pants check | Small tree/rank calculations, plus the import-triggered monodromy computation. The original note records approximately **0.6 seconds**. |
| Reflection-group check | The largest combinatorial task here: orbit closure, permutation-group order, and scalar membership. The original note records approximately **2.6 seconds**, including its imports in that execution. |
| Decimal expansion of the final supplier bound or final lcm | **Not performed or required.** These quantities are specified by finite integer expressions. Their expansion would be a different and unnecessary computational task. |

The recorded times are approximate observations, not portable performance guarantees. Running the scripts in fresh processes repeats imports and, for the group and pants scripts, the monodromy side effect described above.
