# AT20: the relative cell with a specified closed boundary

The complete proof is in `sections/A_relative_period_repair.tex`.

The old source can be arbitrary within the stated torsionfree, H0 and rational comparison hypotheses. Its actual marked elements satisfy ∂h=ρ and ∂x=dh. Consequently y=dx, γ₂(y) and xy supply the required strict K(2) twist data even though x itself is not a sphere parameter.

A common local reference G_N for N a power of two provides explicit h′ and x′ with the same coefficient period. The formula uses the odd unit c_b in AT.119 and is verified directly on every face; its two quadratic expressions vanish in simplex two. Two target row fillings then produce a three-simplex with faces (x−dq,x′,0,0). Although that element is not normalized, its two quadratic expressions are. They give the actual D(3) data needed for the finite resolved-target lifting argument.

These intermediate generator values use only an auxiliary twist. The original old-algebra map is kept fixed. Correcting v₀ by −ε(qy) restores the original twist and changes B by −2J(qy), and ζ by −d(J(qy)). Thus U changes by −J(qy), while V is unchanged. The resulting assignments are actual strict target maps and actual relative repair primitives for both targets on the same source.

A-SAT01 constructs the saturation under the same bounds, and the displayed repair values extend its maps. The proof does not assert that an arbitrary C21 attaching boundary is vertically closed; the equality ∂x=dh is explicit input. Integral transfer and the general boundary a=dHa+Hda require additional work.
