# LaTeX compilation check

2026-11-22 Europe/Berlin, C44_POS /root, GPT-6 Astra Pro, effort not exposed.

The working assembled manuscript compiled successfully to 40 pages using local pdfTeX. This verifies LaTeX syntax and the availability of the referenced internal labels after reruns; it is not a mathematical proof or a visual page-layout inspection. The optional PDF is not part of this first checkpoint.

The container had no prebuilt pdflatex format and no ls-R font database. A format was built locally from the installed LaTeX sources under work/texformat. TEXMF was configured per command to search installed trees directly; the installed lm/cm/symbols/rsfs/euler maps were loaded explicitly. The initial Tectonic attempt failed because its remote bundle URL returned HTTP403; no escalation or security bypass was used. No external dependencies were installed.
