\subsection{Complete nontrivial-group source pieces at eighteen arrows}

\begin{proposition}[Proved: all required nontrivial-minimal-group source pieces]
\label{CP2:A-C2-source-eighteen-complete}
In the joint orientation of
Proposition~\ref{CP2:A-two-object-eighteen-oriented-twenty-two},
the nontrivial-minimal-group source portions of
\[
 (9,3,6),\quad(9,4,5),\quad(9,5,4),\quad
 (10,3,5),\quad(10,4,4)
\]
are completely excluded.  This accounts for all such source
portions in the twenty-two required budgets.
\end{proposition}
\begin{proof}
By Propositions~\ref{CP2:A-positive-corners-nine} and
\ref{CP2:A-positive-corners-ten}, there are two required
nine-element source classes and fourteen required ten-element
source classes.  Their normalized minimal ideal is
\[
 K=\{(i,g,j):i,g,j\in\{0,1\}\},\qquad
 (i,g,j)(k,h,l)=(i,g+h+bjk\pmod2,l),
\]
with sandwich bit $b\in\{0,1\}$.  At order nine the only
outside element is the identity.  At order ten there is one
additional outside actor, and its table is part of the
complete source catalog.  The required source counts are
therefore $2\cdot3+14\cdot2=34$.

Here is the exact right-action input scope.  Use the
description $E,H,A,B$ of
Lemma~\ref{CP2:A-C2-Rees-nine-acts}, with
$U=\operatorname{im}E$, $H=\sigma E$, $B=sE$, and
$AB=H^b$.  A globally fixed ideal state is globally fixed
by the entire source: if $xk=x$ for every $k\in K$, then
for any source element $m$ and any $k\in K$,
$xm=(xk)m=x(km)=x$.
Thus the required no-fixed-state orientation is exactly
the omission of the one-point fixed core type.
The remaining core types have sizes two, two, three and
four: respectively the column core, group core,
partial-overlap core and disjoint free-orbit core.
The middle two occur only for $b=0$.
Every transient state is specified by an arbitrary pair
$(Ex,Ax)\in U^2$.  Typed core permutations, internal core
automorphisms and permutations of transient states exhaust
the isomorphisms.  Enumeration of these data, checked
against Burnside counts in every core stratum, gives
\[
\begin{array}{c|rrr}
 b&|S|=4&|S|=5&|S|=6\\\hline
 0&15&35&127\\
 1&3&5&15.
\end{array}
\]
The four- and five-state lists also agree, map by map up to
state relabeling, with the earlier complete labelled
enumeration.  A separately written referee check compares
the JSON and literal action-table files, recovers all core
strata directly from $E,H,A,B$, and recomputes their
Burnside counts from literal core permutations.  In
particular, the action metadata and the action tables are
explicitly linked.

For a ten-element source, write $a$ for its extra outside
element and $R_k$ for the right transformation of $k\in K$.
Its extension is exactly a transformation $Z=R_a$ satisfying
\[
 ZR_k=R_{ka},\qquad R_kZ=R_{ak},\qquad Z^2=R_{a^2},
\]
with the convention that right multiplication reverses
transformation composition.  If $a^2=a$, the last right
side is $Z$.  The producer scans every transformation and
reduces by the ideal-action stabilizer; the independent
input checker assigns state images in reverse order,
using forced mixed products and partial square equations.
It then checks the full action laws and canonicalizes
under every state permutation.  All $34$ required full-source
right-action families agree, with $418844$ literal action
equations checked independently.

For each right action, every commuting opposite-corner
action is enumerated.  The producer constructs the
centralizer by forced point images and propagates products;
the independent checker scans all $S^S$ transformations
and assigns opposite-element images in a fixed order.
Both use the full right-action automorphism group.
Every required opposite corner through order five is
included; in particular, the $(9,5,4)$ portion includes
$P_5$.  One-column opposite corners are omitted only by
Proposition~\ref{CP2:A-oriented-eighteen-projective-targets}.
There are no further analytic action omissions in these
finite streams.

The complete counts are as follows.  ``Raw'' counts

representatives; ``orbits'' counts state-isomorphism
classes over those representatives.

The remaining $5622$ and $9240$ orbits have respectively

$22948=5622+9240+6579+1507$.  For all $8086$ retained
categories, a separate literal checker verifies the entire

the square primitive or positive-third-homology witness.
The exact ordered stream linker reconstructs every
retained category from its two monoids and both actions.

Four complete seventeen-arrow controls reproduce the old

\end{proof}
