\paragraph{Empty connecting state set in the local graph-source theorem.}
The augmented-graph proof of
Theorem~\ref{CP2:A-projective-local-row-graph-obstruction} is used for a
nonempty connecting state set.  For completeness, if that set is empty,
the category is the disjoint union of the two corner monoids, so its
classifying space is $BM\sqcup BN$.  The opposite graph corner is
rationally acyclic.  For the source, the band--Tor comparison gives
\[
 H_4(BM;\mathbb Q)=\operatorname{Tor}^{A}_2(W,V).
\]
This group vanishes if $V$ is projective.  In the local case, bounded
rational homology of $BM$ makes $W\otimes_A^{\mathbb L}V$ bounded.
Applying Lemma~\ref{CP2:A-local-two-term-derived-amplitude} to the module
$W$ concentrated in degree zero again makes its second derived homology
zero.  Consequently $H_4(BM\sqcup BN;\mathbb Q)=0$, so all products of
degree-two rational cohomology classes vanish.  This separate argument
does not apply the augmented-graph kernel formula to an empty graph.
