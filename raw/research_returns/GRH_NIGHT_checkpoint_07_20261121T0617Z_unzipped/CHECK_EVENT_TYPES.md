# Check-event taxonomy

The published CHECK_EVENTS.tsv uses the event types requested in the prompt. Author and peer readings are targeted proof checks, not independent re-proofs. Each normalized event preserves its original granular label and complete scope in its outcome; working logs retain the original labels. No new check is created by this normalization.
