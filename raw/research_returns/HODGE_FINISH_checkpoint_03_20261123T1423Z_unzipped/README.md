# Hodge papers: finishing checkpoint

This is a working checkpoint, not a final deposit. Both standalone papers include their editable TeX and current compiled PDFs. The first paper treats the uniform finite-field criterion and Weil degree bounds. The second treats construction obstructions and Mumford criteria.

Current mathematical status is in QUESTIONS.tsv; source and verification status is in CHECK_EVENTS.tsv and the new review records. An inherited checked result is not silently relabelled as a fresh independent proof. Page-by-page double review, final clean builds, and final deposit sheets remain to be completed.

External source bodies, downloaded certificate archives, and previous checkpoint ZIPs are excluded. The included reviews are original work of this continuation. No human review is claimed.
