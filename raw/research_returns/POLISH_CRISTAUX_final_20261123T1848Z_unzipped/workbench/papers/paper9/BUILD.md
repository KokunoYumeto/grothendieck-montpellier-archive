# Build

Requires a standard TeX Live installation with pdflatex, amsmath, mathtools, natbib, microtype, lmodern, xurl and hyperref. In this directory run:

```sh
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
pdflatex -interaction=nonstopmode -halt-on-error main.tex
```

The manuscript is a reviewable research draft. The separate proof-unseen main check is pending; its status is not changed by a successful build.
