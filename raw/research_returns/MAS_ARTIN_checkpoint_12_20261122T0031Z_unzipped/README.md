# MAS_ARTIN research package

Read MAS_ARTIN.tex with its modules/ directory. QUESTIONS.tsv records each treated question; CHECK_EVENTS.tsv records actual proof/source/computation events. LEDGER.md records dated gate changes and the scheduled movement reviews. IMPLICATIONS.md maps findings to the predecessor runs and Grothendieck programme. INPUT_CLASSIFICATION.tsv is the exhaustive four-way finding register; INPUT_UNCLASSIFIED_GATES.tsv separately preserves question/gate rows for which a mathematical finding classification would be inappropriate.

The package contains new analysis, source locators, reproducible finite checks and their outputs. Masullo's public source PDF, text extracts and images are excluded. The original attached predecessor files are required to reproduce checks that explicitly read those sources; their paths are recorded in the scripts. No earlier checkpoint ZIP is included.

Research status is active at this checkpoint. An open gate is not a proof or a counterexample. Statements marked checked have the actual check type in the event register; inherited results are distinguished from newly reread proofs. A is the theorem specified in the request; M remains conditional.

Compile MAS_ARTIN.tex from this directory with a standard LaTeX installation. If a PDF is present, it is a convenience rendering of the same modular source. Build and rendering limitations are recorded in the evidence notes rather than concealed.
