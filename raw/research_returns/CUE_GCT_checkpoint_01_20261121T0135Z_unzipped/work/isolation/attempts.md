## Main gate and state

I-G01 is OPEN: construct an explicit polynomial family of polynomial-magnitude variable cocharacters hitting the ROABP coefficient-matroid cones, or a proved weaker joint coefficient-span condition. Nothing in this track establishes polynomial hitting sets for arbitrary width. No P versus NP conclusion is claimed.

## Approaches tried, exact result, next construction

1. **Apply Hoza directly to the arithmetic path graph.** Positive result I-01 for independent vertex or edge variables. The map identifying variables is not equivariant for arbitrary state weights; diamond I-02 refutes the direct transfer. Next: enforce descent through the monomial map.
2. **Identify only paths with the same monomial before isolation.** Exact support requires cancellation of signed coefficient sums. I-12 shows specified coefficient nonzero is coC_=L-complete in a restricted integer model; a logspace graph realization would add a class inclusion not furnished by NL=UL. Next: work with the representable coefficient matroid instead of raw path counts.
3. **Isolate the coefficient basis as a matroid object.** I-03 gives exact functional, flag, circuit, and cone characterizations; I-04 proves projected vertices have unique indexed bases and gives polynomial random weights. The unresolved step is an explicit uniform small family exploiting the matrix-product restriction.
4. **Use positive determinants of coefficient covariance.** I-05 gives a positive Cauchy–Binet formula and the exact projected Newton polytope. Its positivity does not preserve rank after grouped monomial substitution; e1*x+e2*y is a counterexample. Next: isolate a vertex basis and separate its individual weights, which returns to I-G01.
5. **Lift each exponent letter to an independent variable and interpolate the resulting filter from the original black box.** I-06 proves an exponential lower bound for exact fixed linear evaluation simulation, including actual Hoza base-six code filters on three letters. This rules out that implementation; it is not a PIT lower bound.
6. **Repair state weights by Haar averaging.** I-07 proves independent twirling makes the insertions scalar; correlated twirling changes trace invariants and can yield signed coefficients. It does not preserve the desired isolating certificate.
7. **Exterior-power and Gaussian-elimination configuration graph.** I-11 verifies the direct size counts and the determinant-cancellation failure. Constant tensor rank removes one size exponent but not cancellation/descent. Constant coefficient rank alone does not restrict the scalar ROABP task.
8. **Positive coefficient squared norms and exact cubature.** I-09 gives a polynomial transfer-matrix computation from known matrices and torus integral. I-13 proves that any universal exact quadratic reconstruction from Q fixed evaluations requires Q at least (delta+1)^n, already for width-one products; arbitrary signed weights and cross terms do not evade the matrix-rank proof. A root-of-unity product grid attains the bound. Width-one hitting sets nevertheless have n*delta+1 points, so this excludes only the specified reconstruction, not polynomial PIT.
9. **Move forward conditionally to normalization.** I-08 derives exactly the polynomial separating set/finite quotient morphism if I-G01 is closed. The existing quasipolynomial result and deterministic NC orbit-closure test are kept as background, not new consequences.
10. **Geometric translation.** I-10 proves the 1-PS, initial monomial, flag, projected Plucker-polytope and field-flatness dictionary. It distinguishes coefficient matroid strata from automatic all-characteristic rank preservation and coordinate-ring normalization from an optimal algebraically independent hsop.

11. **Joint coefficient compression instead of one BIWA.** I-14 proves the exact Grassmannian/kernel condition and exhibits two rank-one substitutions jointly preserving rank two. This weakens the target, but its Plucker equations contain actual coefficient cancellations and are not determined by a support matroid alone.
12. **Decode or average the actual Hoza seed masks into variable weights.** I-15 proves a bounded-affine-decoder obstruction: low-dimensional integer weight families have Boolean exponent collisions, yielding width-two binomials that vanish on every curve. The raw common alphabet decoder is killed by x1-x3. Nonlinear seed decoding is outside this theorem.
13. **Finite-field row-vector states.** I-16 constructs the exact q^w state support graph with cancellation already performed. A quantitative root-set counting argument proves that fixed small coefficient fields nevertheless require exponentially many base-field evaluations already at width one. Extension-field points are explicitly outside that lower bound.
14. **Invertible factors and row-space flags.** I-17 proves a common-shift, support-at-most-w-1 sampler of explicit size. It is polynomial for fixed width and independent of the variable order. AGKS already established invertible-factor polynomial PIT, so this is a transparent restricted specialization, not a general breakthrough or priority claim.
15. **Regularize singular factors with epsilon I.** I-18 analyzes the exact product-of-pair-differences counterexample suggested by the parent. Generic low-support samples can all have positive epsilon valuation. The next precise target is a unit Plucker coordinate for the compression, equivalently preservation on the special fiber; merely saturating the generic evaluation module performs divisions without producing an original black-box hit.
