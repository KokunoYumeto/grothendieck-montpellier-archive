### 2.3 Th. 7 ("Matsusaka"): numerical equivalence = τ-equivalence (44:6) — SA19-14

- **What he does.** "Th. 7 L'équivalence numérique = τ-équivalence [cycles algébriques sur X projective non
  singulière]", with the marginal name "Matsusaka(?)".
- **Refuted, with the refined statement.** τ-equivalence: Z ~_τ 0 if some nZ, n != 0, is algebraically equivalent to 0
  (SGA 6 XIII, Kleiman; locator unverified). For divisors the theorem is Matsusaka's (Amer. J. Math. 79, 1957; locator
  unverified), and for 0-cycles it is trivial (a 0-cycle of degree 0 is algebraically equivalent to 0). In codimension
  2 on threefolds it is false: Griffiths (Ann. of Math. 90, 1969; locator unverified) showed that on a general quintic
  threefold the difference of two lines is homologically, hence numerically, equivalent to 0 while no non-zero multiple
  is algebraically equivalent to 0 (its Abel-Jacobi image has infinite order modulo the algebraic part). So Th. 7 holds
  for i = 1 and i = n and fails for 2 <= i <= n - 1 in general (the first counterexample n = 3, i = 2). Pro's notes
  (44:6:1-3) ask for the codimension to be separated but do not settle it.
