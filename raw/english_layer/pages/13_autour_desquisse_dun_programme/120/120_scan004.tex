\textcircled{3} $M1$ implies that if one of the $\mathcal M_n$ is empty, they all are -- and then the axioms $M1$ to $M4$ are trivially satisfied. We are going to exclude this \inserted{trivial} case, i.e. assume
\[
(*)\qquad\mathcal M_1\ne\varnothing.
\]
$M1$ implies that if one of the $\mathcal M_n$ contains $\varnothing$, they all contain it. If this is not the case, then each $\mathcal M_n$ (being closed under intersection of two sets) is a filter base on $R^n$.

We exclude this case, i.e. we assume the following relation, stronger than $(*)$
\[
(**)\qquad\varnothing\in\mathcal M_1\qquad(\text{whence }\varnothing\in\mathcal M_n\quad\forall n\in\mathbb N)
