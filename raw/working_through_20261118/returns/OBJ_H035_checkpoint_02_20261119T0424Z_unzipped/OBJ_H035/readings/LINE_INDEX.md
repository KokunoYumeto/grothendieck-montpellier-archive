# Physical-line locator convention

Locators count the main written horizontal rows from the top of the page,
including headings, displayed formulas, and cancelled rows. Printed archive
borders, folio numbers, show-through and marginal text do not receive a main
line number. Interline additions attach to the preceding row as `a`; margin
notes attach with `m`. A multiline diagram receives one number per horizontal
row. These are manual visual counts, not OCR output. Ranges identify the
whole argument; a short quotation may occupy only part of that range.
