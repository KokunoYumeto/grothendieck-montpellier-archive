# The square decides: one four-point price for strict shortening, flatness and the crossing exponent

Two unrefereed preprints of 23-24 November 2026 claim VP != VNP: Anthropic's "VP != VNP over every field" (hexagon:2611.00954) and OpenAI's "VP and VNP are different". Each splits its argument on an open question about the geometry of wires: whether every finite Euclidean configuration is a price (Anthropic's flat hypothesis), and whether a tensor of crossing wires admits a strict shortening (OpenAI). Over every field we prove that a strict shortening in dimension D makes some finite D-dimensional Euclidean configuration a non-price (Theorem A). Assuming Anthropic's Proposition C.3, the unit square is a price if and only if every finite planar Euclidean configuration is, if and only if some finite price is not a tree pseudometric (Theorem B). Assuming also Anthropic's Theorem A.6, the square is not a price if and only if a planar strict shortening exists; in each dimension D, no strict shortening exists if and only if every finite subset of R^D is a price; and the flat hypothesis holds if and only if no strict shortening exists in any dimension (Theorem C). Under the same two hypotheses the exponent of the partial-transpose rank of the crossing tensor is 1 when the square is not a price, and at least sqrt(2) when it is (exactly sqrt(2) given the known upper bound); over C the same holds for the complex Hurwitz sum-of-squares problem (Theorem D). So one four-point metric decides which branch of both case analyses holds. We decide neither branch, and we do not claim that the two preprints' dichotomies coincide. The hypotheses (H_A), Anthropic's Theorem A.6 and Proposition C.3, and both preprints are unrefereed inputs.
