# Adjacent hubs in the all-gate graph problem

[Shared proof map](FLEET_MAP.md) · [Local mathematical evidence](<local>/Documents/Codex/2026-11-22/the-two-tracks-share-no-sound/work/fleet_proof_map/)

Let C(G) be the minimum number of fan-in-two AND, OR and NOT gates for the edge function of a finite simple graph. Write M(G) = |E(G)| + τ(G) − 1 when the graph has an edge. The cover circuit gives C(G) ≤ M(G). The full posted 519 quantifies over every subcubic graph of girth at least seven. The following classification covers a connected graph with **exactly two** vertices of degree three, adjacent to one another. Graphs with further hubs are also allowed in the assigned shard. [519](https://data.pequalnp.com/data/lemma/L-meta-519.ed26ac472458.json) · [105, checked upper bound](https://data.pequalnp.com/data/lemma/L-meta-105.9d8ac69aac51.json)

**Conclusion.** In the exactly-two class, C(G) = M(G) except for one unresolved candidate, the theta with path lengths (1, 6, 6). Its size is either 17 or 18. The reductions below are mathematical deductions from the checked theorems. No Lean formalization of the classification or complete finite circuit search is asserted.

## Core classification

If d₁ is the number of degree-one vertices and μ = |E| − |V| + 1, summing degrees gives d₁ = 4 − 2μ. The tree case follows from 104. If μ = 1, the unique cycle either contains at most one hub, hence at least six consecutive degree-two vertices, or contains both hubs. In the latter case the hubs are adjacent along the cycle since an extra chord would add a cycle. Each supports one pendant path. A cycle of length at least eight still has six consecutive degree-two vertices. These cases fall under 520. [104, forests](https://data.pequalnp.com/data/lemma/L-meta-104.53ddb020f55d.json) · [520, six consecutive degree-two vertices on each cycle](https://data.pequalnp.com/data/lemma/L-meta-520.8ca33af959dd.json)

For the remaining seven-cycle, label the adjacent roots 0 and 1 cyclically. Both lie in the minimum cover {0, 1, 3, 5}. Its circuit cost is 10 by 106. A fresh leaf at either root increases the size by one. Adding a fresh leaf at each of the two roots increases it by two. Fix each leaf to zero, use its essentiality and the nonconstant residual at each application of 014, then use 105 with the same cover. A pair of edges appended as a pendant two-edge path increases the size by exactly three by 546/547. At every iteration an old edge witnesses a true input, while all-zero and the selected endpoint alone witness false on both root slices. Each two-edge extension increases τ by exactly one. Any cover needs an endpoint of the outer edge, and selecting the new internal vertex extends any old minimum cover. Build arbitrary tail lengths from their parity leaves by iterating this operation. This gives C = M for both tails of arbitrary positive lengths. [106, cycles](https://data.pequalnp.com/data/lemma/L-meta-106.612bc014c723.json) · [014, restriction](https://data.pequalnp.com/data/lemma/L-meta-014.17bbe9d3c481.json) · [546](https://data.pequalnp.com/data/lemma/L-meta-546.679862a8a150.json) · [547](https://data.pequalnp.com/data/lemma/L-meta-547.d6614fa46f38.json)

If μ = 2, all vertices have degree at least two. Suppress degree-two paths. The two hubs either each carry a returning path and are joined by a bridge (a dumbbell), or are joined by three paths with disjoint interiors (a theta). This exhausts how the remaining two half-edges at each end of the adjacent hub edge can pair. Each dumbbell cycle has just one hub and at least six consecutive degree-two vertices, so 520 applies. In the theta write the three **edge lengths** as (1,a,b), where 6 ≤ a ≤ b by girth. If a ≥ 7, every cycle contains a path with at least six interior vertices, so 520 again applies.

## A length-six side and a second side of length at least seven

For the theta (1,6,b), use the short cycle as base g = C₇, with adjacent hub variables u and v. Set k = b − 1, the number of fresh interiors. The cover number of the theta is 4 + ⌊k/2⌋. The old cycle and the internal path require these many disjoint cover contributions, attained with an old minimum cover containing both endpoints. The edge count is 8 + k. Thus the target size is 11 + k + ⌊k/2⌋. The base is nonconstant, false at all-zero and at either singleton endpoint. The one-pendant base costs 11 at either endpoint, and the two-pendant base costs 12, as proved above.

* When k = 2h ≥ 6, theorem 573 gives at least 3h + 11, exactly the target.
* When k = 2h + 1 ≥ 7, theorem 574 gives at least min(3h + 3 + 10, 3h + 12) = 3h + 12, again the target.

For b = 6 the odd-thread parameter is h = 2. Theorem 574 requires h ≥ 3. This is the precise missing case of this route. The checked theta theorem 615 covers this graph for the AND/OR-only basis. It gives 18 for that basis and proves that a 17-gate all-gate solution would use a NOT. ## What a 17-gate circuit for the last theta would have to do

Write each long path as u, z₁, z₂, z₃, z₄, z₅, v, with separate vertices on the two paths. The unique minimum cover consists of both hubs and positions 2 and 4 on each path. With both hubs chosen, each internal five-vertex path has unique minimum cover consisting of its second and fourth vertices. With just one hub chosen, each long path requires at least three interior vertices by the matching in the six-vertex portion starting at its omitted hub. Both hubs cannot be omitted. Thus the graph has 13 edges, cover number 6, and M = 18.

For every odd-position interior vertex z, fixing it false removes two edges and keeps cover number 6 (a cover of the remaining graph of size at most five, extended by z, would contradict uniqueness). Up to isolated inputs the remainder is a seven-cycle with either one four-edge tail or two two-edge tails, so its minimum circuit size is exactly 16. By 014 this proves C ≥ 17. If equality holds, 168 and 169 applied after relabelling force each of these **six** variables to have exactly one reader in every least circuit, a binary OR with one distinct earlier wire. [168, unique reader](https://data.pequalnp.com/data/lemma/L-meta-168.cc39abe0e028.json) · [169, OR reader](https://data.pequalnp.com/data/lemma/L-meta-169.752bf4ba05b4.json)

In fact every one of these six other operands would have to be a **gate output**. If the sole reader were z ∨ w with another input w, there is a neighbor r of z such that r = w or r is nonadjacent to w. Otherwise w and z have both neighbors of z in common, forming a four-cycle. Turn on just w and r, interpreted as one vertex if equal. The edge function is false with z = 0 and true with z = 1. The putative reader stays true. Hence these six readers are distinct, none can be the first gate, and at least one NOT is also required by 615.

The following costs identify what remains for a three-/four-gate elimination. The entries are exact. At zero the graph is a tree or a short cycle with tails covered above. At one, the neighbors become independent free OR inputs and the residual edge graph is induced by deleting the closed neighborhood. It is a forest or a seven-cycle with tails. Each free OR input adds exactly one by restriction and the one-OR construction.

## At least four maximal independent sets would have a hazard

Write \(p_1,\ldots,p_5\) and \(q_1,\ldots,q_5\) for the interiors of the two long paths. In the following numbering \(u=0,v=1\), the \(p\)'s are 2 through 6 and the \(q\)'s are 7 through 11. Evaluate a hypothetical 17-gate circuit on the ternary assignment that gives the unknown value to the members of a maximal independent set \(I\) and zero to the other vertices. At least four of the 27 such assignments must give an unknown output. All their Boolean completions give zero.

To see this, let \(D(S)\) be the unknown indicator of the output when the unknown set is \(S\). Its zero-baseline positive circuit has **at most 15 binary gates**. Indeed, 615 requires at least one NOT in the original 17. At least one AND or OR must have operands of different all-zero baseline values. Otherwise complement each baseline-one wire in the Boolean description. All primaries have baseline zero, NOTs then copy their operand, and De Morgan's law turns every binary gate into a positive gate computing its baseline-relative Boolean value. The output has baseline zero, giving a positive circuit of at most 16 gates for the original edge function, contrary to 615. Every mixed-baseline gate gives just a projection in the positive circuit for \(D\). Least circuits here have no constant gates, identities or repeated operands, which can be simplified. The derivative is monotone and \(D(S)=1\) for every set \(S\) containing an edge. [Zero-baseline construction](hazard_faces.md) · [615](https://data.pequalnp.com/data/lemma/L-meta-615.4ba5d371bde1.json)

Suppose \(\mathcal H\) is the set of hazardous maximal independent sets. For an independent \(S\), write \(X(S)\) for the maximal independent sets containing \(S\). Whenever \(X(S)\not\subseteq\mathcal H\), monotonicity forces \(D(S)=0\). On a face with disjoint coordinates \(P\) pinned to one and \(Z\) pinned to zero, the derivative therefore agrees with the original edge function throughout if every inclusion-maximal independent set on the face has an extension outside \(\mathcal H\). Such a face describes the *Boolean function of the unknown indicators*. Pinning an indicator to one makes that input unknown in the original ternary test.

The exact cofactor on this face is obtained by adjoining to the residual edge function one free OR variable for every unfixed neighbor of \(P\). The residual graph is induced by deleting \(P\), \(Z\), and the neighbors of \(P\). If it has an edge and the face is proper, the graph is a forest or a surviving seven-cycle with tails, possibly with detached paths and isolated vertices. The proofs above give its exact size; a detached forest contributes its number of edges plus its cover number by 522. Each additional free OR variable costs one. Cofactors with an edge already forced are constant. A cofactor with no residual edge is a disjunction of free inputs and cannot account for any of the strict bounds below. [522, disjoint forest summands](https://data.pequalnp.com/data/lemma/L-meta-522.cd24c6e8e509.json)

If a pin is essential in the current restriction of \(D\), fixing it saves at least one gate provided the final cofactor is nonconstant. To witness essentiality of an unpinned vertex \(x\), it suffices to find an independent assignment \(S\) extending the earlier pins with \(x=0\), \(X(S)\not\subseteq\mathcal H\), and an edge in \(S\cup\{x\}\). The checker tries the pinned-one set and that set with one neighbor of \(x\) included. It tries every order of the pins. Hence if the exact cofactor size plus the number of successively essential pins exceeds 15 on a face of agreement, the proposed \(\mathcal H\) is impossible.

The 14 one-pin, 16 two-pin and eight three-pin faces with this strict numerical inequality leave 52, three and then **one** of the 351 two-element families, in that order. The last pair is

The one-pin tests alone exclude every singleton family. For the last pair, \(D\) agrees with the edge function wherever \(p_3\) is included, and \(D\) depends on \(p_3\): a singleton neighbor is stable, but including \(p_3\) creates an edge. Every vertex belongs to at least nine maximal independent sets, so a family of two cannot cause a singleton hazard. In the inherited circuit for \(D\), that input has its unique OR reader. If the other operand had baseline one, the mixed gate would project away \(p_3\) and \(D\) would ignore it. Otherwise the derivative keeps the binary OR, counting it even if its other input simplifies to zero. When \(p_3=1\), this gate becomes one and at least one downstream binary reader is eliminated. Such a reader exists since the restricted derivative is nonconstant and the input is essential. This gives at most 13 gates for a cofactor of size 14, ruling out the last pair.

The same two-gate saving applies whenever an odd-position input is the **first** pin, set to one, with its essentiality witnessed and the final stable cofactor nonconstant. The tests with this extra saving leave just five of the 2,925 three-element families.

To exclude the five remaining triples, apply 570 to the positive derivative function \(D\), taking its distinguished variables to be **all ten interiors**. Here is the finite verification. For each pair of interiors and each three of its four patterns, search for an exterior assignment under which one pattern contains an edge and another is independent with a maximal extension outside the proposed family. This proves the no-three-equal condition. For the reset condition, the fixed exterior consists of just the two hubs. If both are on, an edge is already present. For each of the other three hub assignments and each interior \(y\), find an independent set \(S\) with exactly this exterior, \(y\notin S\), a maximal extension outside the proposed family, and an edge in \(S\cup\{y\}\). These witnesses prove that \(D\) changes from zero to one. The derivative is monotone, is zero at the origin, and has nonconstant restrictions at each interior. For the last assertion, the cofactor-size witnesses just below give nonconstant restrictions of both kinds.

For each of the five families and each interior \(x\), further stable faces give \(C(D|_{x=0})\ge13\) and \(C(D|_{x=1})\ge12\). These bounds use the same successively essential pinning test, this time starting **after** the \(x\) pin and giving no charge for that pin. They use no assumed exact minimum or stability for the original restricted circuit. By 570, some false restriction should cost at most \(15-3=12\) or some true restriction at most \(15-4=11\). Both alternatives contradict the witnessed lower bounds. The same tests leave 21 of the 17,550 four-element families. These survivors are necessary conditions for a four-hazard circuit. The enumeration checks independent sets, exact cofactor sizes and explicit witnesses. It does not synthesize a circuit. **If exactly four tests are hazardous, the lone negation must be internal and shared on its input side.** The finite face test excludes a derivative of size at most 14 for all 21 surviving quadruples, using only the ordinary one-gate saving per essential restriction. In particular the original circuit must have exactly one NOT and exactly one mixed-baseline binary gate. The NOT produces baseline one. With this sole negation, the first binary gate reached from it must be mixed, since there is no distinct earlier baseline-one signal. The mixed gate must be an AND, as an OR would leave a baseline-one signal that cannot reach the baseline-zero output without a second mixed gate. Thus the entire nonpositive part has form \(B\wedge\neg A\), with \(A,B\) positive functions. The NOT feeds only this AND. The inherited derivative replaces the guarded wire by \(B\). [534, minimal-circuit normalization](https://data.pequalnp.com/data/lemma/L-meta-534.54849fdf902f.json)

In every surviving quadruple the four maximal sets have **empty intersection**. At every hazardous set \(I\) one must have \(A(I)=B(I)=1\), since otherwise the ordinary circuit and the derivative agree on the guarded wire and hence on the output. Consequently neither \(A\) nor \(B\) can be a primary variable. Some other surviving part of the derivative must use the gate computing \(A\). If the entire use of that gate disappeared with the NOT, removing it would leave at most 14 positive gates. The checker prints all 21 quadruples as twelve-bit vertex masks in the numbering specified above.
