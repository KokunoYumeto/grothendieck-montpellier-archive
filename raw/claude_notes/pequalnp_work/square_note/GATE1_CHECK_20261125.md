## The hinge, strongest checked form

Fix a field k. The four levels, from weakest to strongest inputs:

**1. Unconditional.**
- A strict planar shortening implies that some finite planar Euclidean configuration is not a price.
- New in run 98's final (statement level, not checked here):
  - no strict shortening has width m ≤ 6, in any dimension and with any layouts (SH-60b);
  - a planar shortening with two terms needs width at least 8 (SH-38).

**2. Under C.3.** These are equivalent:
- the unit square is not a price;
- the centred square is not a price;
- some finite planar Euclidean configuration is not a price;
- every finite price is a tree pseudometric;
- no four-party price, and no spectral point, violates the tree rule strictly.

In this branch, over C, the prices are exactly the tree pseudometrics. Over every field that holds only with PG-TREE-ALL.

**3. Under C.3 and A.6.** The conditions above are also equivalent to the existence of a strict planar shortening.
Run 98 and run 99 prove this by different arguments. Per dimension D (SH-08 = Q3b): no D-shortening ⟺ all finite
D-configurations are prices; and flat ⟺ no strict shortening in any dimension.

**4. Under C.3 and A.6, with lem:pt-upper and prop:optimal-crossing-hubs.**
- The crossing (partial-transpose) exponent ρ_k = lim log P_k(q)/log q exists.
- **ρ_k = 1 iff the square is not a price; ρ_k = √2 iff it is.**
- Over C the same holds for the complex Hurwitz exponent of σ_C.
- So any fixed superlinear lower exponent for the Hurwitz problem decides the branch: the square is a price, and there
  is no strict planar shortening.
