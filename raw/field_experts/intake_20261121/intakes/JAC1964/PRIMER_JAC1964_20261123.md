## 1. Th. 4: the primitive incidence quotient carries a polarization

### JAC-T4.1, the primitive incidence summand `[TPC]` (lines 1478–1539)

- **Statement.**
  - For A abelian of dimension 2m − 1 and h ample, the cohomological projector e_h onto P^{2m−1}(A) = ker L_h is
    algebraic.
  - It induces an idempotent on Saito's P^m(A).
  - Its image B = P^m(A)_prim carries a nondegenerate symmetric rational incidence correspondence d_B.
- **Proof.**
  1. The Lefschetz standard conjecture holds for abelian varieties (Kleiman 1968, 2A11).
  2. Incidence detection (JAC-P01): a correspondence with zero odd action acts as zero on P^m.
  3. e_h is self-transpose, by hard-Lefschetz orthogonality.
  4. Saito's transpose compatibility (Nagoya 75 (1979), Prop. 4.4) makes the duality block-diagonal.

### JAC-P01, incidence detection by the odd realization `[TPC]` (lines 575–625)

The homomorphism T → Pic⁰(S) induced by Ξ∘Z is determined by its rational Tate-module action, which is faithful on Hom of
abelian varieties. That action is the mixed component Ξ_*∘[Z]_{1,2q−1}. No standard conjecture D is used.

### JAC-T4.2, the curve test `[TPC]`, `[REC]` (lines 1540–1599)

- **Statement.** For ξ ∈ H¹(C) ⊗ H^{2m−1}(A) algebraic with (1⊗L_h)ξ = 0, set
  w = (b − 1)!·(L_θ^{b−1})^{−1}(a×1)_*ξ on J(C) × A. Then
  - H^b w = 0;
  - ∫w²H^{b−1} = (b − 1)!∫_{C×A} ξ²;
  - hence (−1)^m∫ξ² ≥ 0, with equality only for ξ = 0, by 032 Cor. 8.4 on J(C) × A.
- **Mechanism.** The Poincaré formula a_*[C] = θ^{b−1}/(b − 1)!.

### JAC-T4.3, cote 44 Th. 4 for abelian varieties `[TPC]` (lines 1600–1688)

- **Statement.** Accepting 032 Cor. 8.4: for every abelian A of odd dimension 2m − 1 over an algebraically closed field of
  any characteristic, and every rational ample h, the class ℓ_B = ((−1)^m/2)·Δ_B*d_B is ample on P^m(A)_prim.
- **Proof.**
  1. Δ*d_B/2 induces d_B (the biextension class), so ℓ_B is nondegenerate.
  2. For each curve C → B, deg_C ℓ_B = ((−1)^m/2)·∫z_C². This is refined pullback; the C44_POS intake derived it on
     22 Nov.
  3. By T4.2 that degree is ≥ 0, so ℓ_B is nef.
  4. A nef class whose map is an isogeny is ample, by Mumford's index theorem.
- **Sign calibration.** For m = 1 this gives the elliptic principal polarization.

## 2. Th. 5: the height formula fails, and its correction

### H9-C1, the counterexample `[TPC]`, `[REC]` (lines 1884–2050)

- **Setting.** X is the 2m-dimensional quadric uv + Σw_iz_i = 0, with the pencil au + bv = 0. Every fibre is
  geometrically integral (the two singular members are cones).
- **The cycle.** Z = P_{∞,+} − P_{∞,−}, a difference of m-planes from the two families. Then Z|_Y = 0 in CH^m(Y), through
  the K-conic.
- **The failure.** (−1)^m Z² = 2, while the height is 0.
- **The local terms.**
  - e = j_*p*δ_B, with u_{∞,0} = ±t_X − e.
  - The matrix is diag(4(−1)^m, 4(−1)^m).
  - Each fibre's Schur term is (−1)^m, so each node contributes 1, and the two cancel the 2.

### H9-T1, the corrected formula `[TPC]` (lines 2051–2117)

- **Statement.** h_m = (−1)^m·(deg(x₀y₀) − Σ_s a_s^t M_s^{−1} b_s) for admissible extensions. Admissibility requires the
  extensions to annihilate each vertical radical.
- For m = 1 this is Shioda's correction. It is the same theorem as SIGN_NEXT SN-44-01.

### H9-T2, no correction under injective specialization `[TPC]` (lines 2118–2209)

- **Statement.** If H^{2m}(Y_s) → H^{2m}(Y_η̄) is injective at every singular fibre, there is no correction term.
- **Proof.** The cycle class and cap product.
- At an ordinary node, injectivity holds iff the vanishing cycle is nonzero (SN-44-03).

### JAC-P07 `[TPC]` (lines 2724–2798, read for the C44_POS seed): condition A is automatic for abelian pencils

- **Statement.** For an abelian 2m-fold the variable rank is deg h^n − C_n > 0. Then every vanishing cycle is nonzero
  (SGA 7 II, XVIII 6.2, 6.4.2.3, 6.6), so condition A holds in every characteristic.

### H9-T7, the whole height group `[TPC]` (lines 2868–3054, read for the C44_POS seed)

- **Statement.** For an abelian 2m-fold pencil with axis κ: B → X there is a canonical isometry
  H/H₀ ≅ A_X ⊥ A_B, with form (−1)^m∫_X zz′ + (−1)^{m−1}∫_B ww′.
  - A_X is the primitive algebraic middle classes of X; A_B = ker κ_* on the algebraic classes of B.
  - H₀ is the image of the homologically trivial cycles of the blow-up.
- **Proof.**
  1. The blow-up formula (Fulton 6.7(e)).
  2. H9-T2's admissibility.
  3. Adapted pairs (Z₀, w₀) through the algebraic inverse of L_h².
  4. The vertical classes are F·q*u.
  5. The exceptional self-intersection.
- **Positivity** needs 032 for the ambient term in general. It is unconditional on powers of an elliptic curve
  (C44-A42b).

### H9-T17, after a finite cover `[TPC]`, `[REC]` (lines 4229–4559)

- **The splitting.** z = z₀ + hD_z, D_z = ψ_h^{−1}alb(hz). This uses Kahn, *Refined height pairing*, arXiv 2009.00533v7:
  L6.1 and Thms 5.6, 6.2, 6.6.
  - The Albanese-primitive part is semipositive in characteristic 0 (S.-W. Zhang, arXiv 1001.4788, Th. 1).
  - The Lefschetz part is negative modulo trace (Kahn 6.6).
- **The example.**
  - E⁴ with a pencil of class d·Σa_i, a cover C = E → P¹, and P = Δ − C×0 − 0×E.
  - H(hD, hD) = 6d³·(−2) = −12d³.
  - The positive direction (a₂ − a₃)D gives +4d.
  - The norm is zero.
- **Scope.** This restricts *semipositivity* to the Albanese-primitive domain. The corrected identity H9-T1 still holds on
  every admissible cycle. JAC1964 part 2 §3 stated this too strongly; the C44_POS intake corrected it.
