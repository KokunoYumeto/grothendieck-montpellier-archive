Arbitrary non-PL boundary data require a prior compatible replacement, and straightening the total-space map while preserving finitely many faces need not preserve each parameter fibre. Such relative control in every required dimension would support a weak-equivalence comparison, with a further model-dependent step if an actual homotopy equivalence is asserted. The checked literature supports T05–T07; this task does not certify the full assertion for all proposed tame theories, map types, and systems.
