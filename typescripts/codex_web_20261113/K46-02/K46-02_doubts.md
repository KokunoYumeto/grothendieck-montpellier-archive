# Legibility and limits

All 16 whole-page images and all 48 supplied thirds were visually inspected, with a second reading of every page and additional enlargements/rotations. No OCR, external transcription, literature, or web source was used. The source is entirely handwritten; the sideways pencil title on 73 has an unknown hand.
