\uline{Dualité} Si $\mathbb D$ est un dérivateur, on va définir un dérivateur \uuline{dual} $\mathbb D^\circ$ par
\[
\mathbb D^\circ(I)\overset{\text{déf}}{=}\mathbb D(I^\circ)^\circ
\]
Les coefficients sur $I$ \deleted{\unsure{pour}} de type $\mathbb D^\circ$, sont les \unsure{coefficient|coefficients} sur la cat. opp. $I^\circ$ à $I$ de type $\mathbb D$, et en tant que cat. c'est la cat. \uline{opposée} de celle des coeff. de type $\mathbb D$ sur $I^\circ$. Pour définir la loi 2-fonctorielle, on note que pour $I,J$ dans $\mathrm{Diag}$ on a
\diagram{\begin{tikzcd}[ampersand replacement=\&,column sep=large]
\underline{\mathrm{Hom}}(I,J)^\circ \arrow[r,"{\mathbb D_{I,J}}"] \arrow[d,"\text{dualité}","{\rotatebox{90}{$\scriptstyle\sim$}}"'] \& \underline{\mathrm{Hom}}(\mathbb D(J),\mathbb D(I))\arrow[d,"\text{dualité}","{\rotatebox{90}{$\scriptstyle\sim$}}"']\\
\underline{\mathrm{Hom}}(I^\circ,J^\circ)\arrow[r,"\Theta"] \& \underline{\mathrm{Hom}}(\mathbb D(J)^\circ,\mathbb D(I)^\circ)^\circ
\end{tikzcd}}
où $\Theta$ est l'unique foncteur rendant le diagramme commutatif. Alors $\Theta^\circ$ est un foncteur
\[
\underline{\mathrm{Hom}}(I^\circ,J^\circ)^\circ\xrightarrow{\unsure{D|\mathbb D}}\underline{\mathrm{Hom}}(\mathbb D(J)^\circ,\mathbb D(I)^\circ),
\]
c'est ça par définition $\mathbb D^\circ_{I,J}$.

Si $\mathbb D$ est défini par $(\mathcal M,\Sigma)$, alors \inserted{$\mathbb D^\circ$ par} $(\mathcal M^\circ,\Sigma^\circ)$, puisque
\[
\deleted{\unsure{\mathrm{Hom}}}\,(\mathcal M^\circ)_I\overset{\text{déf}}{=}
\underline{\mathrm{Hom}}(I^\circ,\mathcal M^\circ)\simeq
\underline{\mathrm{Hom}}(\underset{\substack{\shortparallel\\(I^\circ)^\circ}}{I},\mathcal M)^\circ
\simeq\deleted{\unsure{\mathbb D(I)}}(\mathcal M_{I^\circ})^\circ
\]
et $\Sigma^\circ_I$ est déduit de $\Sigma_{I^\circ}$, \deleted{\unsure{par}} d'où
\[
\big((\mathcal M^\circ)_I\,\Sigma^\circ_I\big)^{-1}\simeq
\big(\mathcal M_{I^\circ}\,\Sigma_{I^\circ}^{-1}\big)^\circ=\mathbb D(I^\circ)^\circ
\]
