## Title sheets, dates and page counts

There is no separate title sheet, written date or stated page count on scans 192–206. Each has a manuscript page number at the head, from 141 on scan 192 through 155 on scan 206, increasing by one on each leaf. The archive numbers run from 192 to 206 at the lower left. Scan 197 (manuscript 146) has the internal heading « 3.4. Critères pour les carrés homotopiquement cocartésiens ». None of these sheets is a typescript.
