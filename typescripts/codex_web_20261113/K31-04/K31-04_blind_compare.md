# Blind collation

The blind TSV preserves the readings as written before the page files were reopened. Comparison preserves case, accents, numerals and punctuation, removes spacing and editorial wrappers, and equates common TeX spellings of the same sign. An excerpt may identify only part of a correction. For repeated strings, isolated symbols and every reported difference, the locus TSV fixes the first-pass character intervals and the script carries them through every recorded audit and witness edit. An ellipsis in the comparison column separates nonadjacent intervals. For other excerpts it searches the page. At an anchored place the fourth column is the normalized first-pass excerpt. Elsewhere it is an approximate nearest string and the decision identifies the reading on the ink. The last column distinguishes an actual textual revision from abbreviated blind notation, superposition, segmentation or layout.
