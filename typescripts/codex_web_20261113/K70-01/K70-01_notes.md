# K70-01 — source notes

## Steps the pages themselves mark as unverified

- **006, opening:** “Sauf erreur”. This qualifies the claim that the regular combinatorial object is specified by its incidence geometry.
- **007, upper-left margin:** “à vérifier”. The note stands beside the reformulation using affine flags and an affine group action.
- **009, middle:** “donc il faut encore à vérifier que” followed by `sigma_j f_i=f_i si j<i`. The awkward phrasing is retained; the page then lists the group relations.
- **013, upper middle:** a **?** above the implication from `sigma_i^2 s_{i+2}=s_{i+2}` to `sigma_i^2 s_j=s_j` for `j>=i+3`.
