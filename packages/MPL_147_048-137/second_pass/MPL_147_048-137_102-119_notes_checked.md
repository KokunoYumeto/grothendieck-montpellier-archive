**O1 — scan 103, (146); compare 102. Kind: unpursued implication. Confidence: medium.** The corrected top arrow
Π₁M_G → Π₁M_{G′} makes Π₁M contravariant in normalization morphisms G′ → G. On 102 the corresponding arrow "ΠM_{G′} — ΠM_G"
has no clear head, so 103 is the first place where the direction is fixed in ink. The bottom row
Π₁M_{G̃} → Π₁M_{G̃′}, through forgetting marks (147) with Î′_α ⊂ Î_α, runs in the same direction. This bears on the
first-pass note R101.4 (reversed graph and groupoid directions).

**O2 — scan 109, the chain I(d) "(drapeau maximal de codim d)" and the K_d margin. Kind: own idea. Confidence: high
(finite combinatorics).** A codimension-compatible embedding of the maximal chain d > d−1 > … > 0 into P(I(x))° at a point
on exactly d branches is a complete flag of branch intersections, the same as a total order of the d branches. So
D_{I(d)} → D_d is the 𝔖_d-torsor D^!_d, as he states. For K_d (a least element of codim d and d elements of codim 1),
the compatible embeddings are the bijections between the d atoms and the d branches. That is again an 𝔖_d-torsor, and
𝔖_d acts by permuting the atoms. This is what the margin asks for ("pour ceci; il faut prendre … l'ens ordonné K_d").

**O3 — scans 105 and 109–117, the "!" notation. Kind: reading question. Confidence: medium.** The principal cover is
written D^!_d, and on 105 the germs carry Γ^!_G. On 109–112 the "!" stands under a struck tilde: he first wrote D̃ and
changed it, which separates the ordering torsor D^!_d from the d-sheeted cover D̃_d (the 117 margin: "D_{d,1} est le rev.
à d feuillets de D_d qui correspond à D^!_d"). On 112 the old notation survives in "rev. principal D̃_d de D_d, de groupe
𝔖_d" and in D̃_d ∧_{𝔖_d} H(J) on the left of (162). A contracted product over 𝔖_d needs the torsor, so that left-hand side
should be read with D^!_d. The transcription keeps D̃_d as written.

**O4 — scan 111, inserted bound "(≠d)". Kind: reading question / unpursued implication. Confidence: medium.** Read as ≠,
the insertion goes with the other insertion "≠ e_J": an element x ≠ e_J has codimension δ ≠ d. With the codimension
function strictly decreasing (108 margin) and e_J the least element, δ ≠ d is the same as δ < d. That is the case where
the flag Δ(d,δ) of type d,δ is defined ("si δ<d!"). The equal case δ = d, the singleton flag, is exactly the one he
cancels ("resp. •_{d=δ} (si δ=d)").

**O5 — scan 119, margin "𝒟 est une catég. dans la catégorie (An)_{D_0}". Kind: unpursued implication. Confidence:
medium.** The deployment structure is an internal category in analytic spaces over X = D_0. (178) gives the structure

simplicial analytic space over X whose n-simplices are the flag spaces D_{d_0,…,d_n}, and (165) is its Segal condition in
degree 2. The site version of the Remarque on 118 then has to be stated over a base object X of the site.

**O9 — scan 116, "Mais finalement si, c'est une conséquence de c)". Kind: own idea. Confidence: medium.** The first-pass
countermodel (R116-02) shows that the source-fibre shape in c) alone does not force an arrow to be determined by its
source and target. Add to c) the hypothesis that, for each object a, the target map restricted to the arrows with source

as including it.
