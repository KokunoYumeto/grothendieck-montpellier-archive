## Conventions followed and choices

- **½:** written `$\frac12$`, as the first pass wrote it at its first occurrence (045, heading). Applied at 044
  l.23.
- **Doubts that mix a sign and a word:** written in text mode with the sign in `$…$`, for example
  `\unsure{$\leftrightarrow$|$\rightarrow$|donc}`. The first pass wrote sign-only doubts in math mode.
- **Subscript order z,Z / Z,z:** the first pass treats the same letter shapes in two ways.
  - On 033 it writes `z,Z` without doubt.
  - On 034 it writes `\unsure{Z,z|z,Z}`.

  Both are kept. Neither the shape nor the size of his z and Z decides the case in a subscript. On 032 l.16 the
  ink does decide, and reads `z,Z`.
- Struck words are kept as `\deleted{…}`, insertions as `\inserted{…}`, and margin notes as `\margin{…}`, as in
  the first pass.
